# 写给高中生：三个反直觉的数学问题

2026年10月17日完成的三篇文章，面向**没有编程基础的高中生**。三篇都从一个可以自己动手做错的问题出发，用同一个例子一路走到手算、程序验证与适用边界。每篇的结论都能用一支笔、一张纸复核；代码的作用是把论证里能跑的部分真的跑出来给读者看。

1. [换，还是不换？](../articles/2026-10-17-monty-hall-switch-or-stay/read.md)  
   三扇门、一辆车、两只羊。用九种情形的完整枚举数出 1/3 与 2/3，再用贝叶斯、二十万次模拟和一百扇门版本互相印证。含一个关键对照：把「主持人知道答案」这一条去掉，答案就从 2/3 变回 1/2。另有一个容易算错的细节——**主持人的策略不改变总体胜率，却会改变「在他开了某扇门的条件下」的胜率**。17 幅正文图。

2. [七座桥，为什么一座都走不通？](../articles/2026-10-17-konigsberg-seven-bridges/read.md)  
   从 1736 年的哥尼斯堡出发，讲清欧拉「把形状扔掉、只留连接」这一步，以及「进去一次就得出来一次」这个奇偶论证。含把判定规则与暴力搜索在 432 张图上对撞的穷举校验。结尾讲到两个现代用途：城市扫雪与收垃圾的最少重复趟数（含一个**简单公式失效的反例**），以及用 de Bruijn 图从碎片还原 DNA 序列——包括**重复片段为什么会让它失效**。15 幅正文图。

3. [无穷也有大小：一条对角线怎样分出两种无穷](../articles/2026-10-17-cantor-counting-infinity/read.md)  
   从希尔伯特旅馆讲到一一配对，再到康托尔的对角线。用三轮实际构造说明「加进表里再构造一次还是逃出来」。含一个真实陷阱的说明：为什么新数里不能出现 0 和 9。最后落到「可数」与「不可数」的区别，以及同一个手法如何被图灵用来划出计算的边界。18 幅正文图。
