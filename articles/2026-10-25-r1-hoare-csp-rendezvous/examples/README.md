# 复算会合、缓冲与死锁

这是本篇原创的有限状态教学模型，不是完整 CSP 解释器。输入直接定义在 experiment.py 中：六个有限直线程序、固定整数、固定进程名；没有随机抽样。

从本目录执行，结果写到仓库外的相对目录。下列位置按实际检出位置调整；不要把审计输出放回文章目录。

```sh
PYTHONDONTWRITEBYTECODE=1 \
python experiment.py \
  --out \
  ../../../../csp/results.json
```

该脚本只依赖 Python 标准库。本文实际版本为 Python 3.12.14。比较生成结果与随文 results.json，应得到相同状态、边、轨迹和断言；不同 Python 版本会改变记录的版本字段。

程序将“已完成多少条指令”作为位置；状态同时保存每个进程的局部整数、记录列表和每条有向通道的队列。容量零时，匹配发送与接收同时推进双方；容量正时，发送入队和接收出队分别推进一方。内部加法与记录各自为一步。程序用广度优先搜索合并完全相同的状态，并列出所有可执行边。

关键检查：每次会合改变恰好两个位置；其他动作改变一个位置；队列不超容量；流水线每个完成状态均记录 12、15；双方先发无缓冲时初始即死锁；改序后完成；各发两次且各一格时满队列死锁。有限穷举检查不保证枚举器无错误，不证明任意 CSP 程序。

本模型不实现向已终止伙伴通信的原 CSP 失败事件。四个无缓冲场景不触发该边界；队列扩展允许取走已结束发送者之前入队的消息，这不是再次与该进程会合。不要借它解释原论文的自动终止、现代 close 或异常行为。它也没有循环、输入守卫、动态进程或调度公平假设。

需要 Pillow、fontTools 与 Noto Sans CJK 中文字体。绘图读取本目录 results.json；若改输入，应在独立副本中同步更新数据后再绘图。

```sh
PYTHONDONTWRITEBYTECODE=1 \
python build_figures.py \
  --out \
  ../../../../csp/assets
```

生成九张原创模型图以及相邻 examples 目录内的元数据。真实浏览器截图不会被绘图脚本重绘；其既有身份元数据被保留，图片仍以正文 assets 中的真实截图为准。模型数值和状态连接从 JSON 读取；排版坐标不表示物理量。

## 查看实际状态图

在本目录启动普通静态 HTTP 服务：

```sh
python -m http.server 8823 \
  --bind 127.0.0.1
```

浏览器打开本机 8823 端口的 viewer.html。选择场景后，按钮列出当前所有合法动作；每按一次就沿一条已枚举的边前进。没有按钮时，页面明确区分完成与死锁。“回到初始状态”可以重置。结果加载失败时提供重新载入按钮。

查看器是 Python 结果的浏览界面，既不启动并发线程，也不声称测量执行速度。正文两幅界面图来自 Chromium 154.0.8037.57；不是绘图脚本仿造的输出。
