# 缓存行权限模型

在本目录用Python 3标准库运行：

```sh
python coherence_lab.py
```

正文的短调用在同目录保存/运行即可。`run_stores([0,1]*4, separated=False)`只让两核心依次执行写入；True把y从1032移到1088。每个计数器8字节，缓存行64字节。

每次事件完全结束后才开始下一次，缓存容量无限，MESI稳定状态。写入函数接收已经算好的数值，不把读改写复合操作模拟成原子指令。程序自身是单线程，不会启动硬件性能测试。

`read`：缺行时申请副本；其他M提供最新值并更新模型主存，双方变S；无其他副本时取得E。

`store`：I或S需申请写权限并使其他有效副本失效；E或M可本地写。M向新M交接时允许直接传递最新数据，不强制经过主存。

`evict`：M逐出先写回；S或E可直接丢弃。剩下的S不自动升级E。

模型记录写权限申请、读取申请、实际副本失效、填充、写回、本地写事件。它们不是时钟周期、网络包数或实测耗时，也不覆盖真实协议暂态、并发消息、存储缓冲、NUMA、预取、容量冲突、死锁及活锁。

实际测试：8191种写者序列；65536种四事件序列；种子1984348的100000次随机事件，以及对齐、只读、写读示例。每事件用独立的顺序值账本检查有效副本及主存关系。有限检查不是硬件协议的形式证明。
