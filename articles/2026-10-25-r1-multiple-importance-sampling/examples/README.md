# MIS离散实验与真实结果查看器

本次环境：Python 3.12.14、NumPy 2.4.6、Pillow 12.3.0；制图使用fontTools与Noto Sans CJK。请在自建虚拟环境中安装依赖，从此目录运行：

```sh
python -m pip install numpy==2.4.6 Pillow==12.3.0 fonttools
python mis_model.py
python build_figures.py
```

`results.json`保存精确两格结果、渲染条件、误差、种子和一个固定点的概率表；`render-values.json`保存有效点顺序、法线、颜色、参考、四种随机估计和解析方差。`output/`包含参考、四种估计、四张误差图、一个环境表，共10个RGB PNG。球原图160×88，6,744个有效点；环境表64×32。球外深色背景不参加误差统计。

模型把32×64等立体角单元的中心方向当成完整离散方向集合，Δω=4π/2048。参考是这个有限和；没有声称它等于连续积分。两个球分别独立受环境光，忽略彼此遮挡和间接反射。镜头为正交，视向球的正z半面。球半径0.91、中心横坐标±1.12，像素坐标按源码36像素/场景单位映射；m=6和180的Phong瓣加0.15漫反射项，固定颜色最后相乘。

四种方法固定32个估计项，MIS各16个；概率表、贡献和参考在教学程序中预先全算，因此不是生产效率测试。每方法独立PCG64种子2026102500至2026102503，按有效像素行优先消费，MIS每点先光策略后材质策略。固定点4,000次重复检查另用2026102600至2026102603，不能把两次实验当作同一随机序列。

误差/方差均指未乘RGB颜色的线性标量；球图统一乘颜色、做c/(1+c)映射和sRGB编码。误差图用蓝0到红≥0.5的固定映射，统计不裁剪。环境表仅按L/(1+L)映射灰度数值，不是球图的完整显示流程。所有放大和裁框只为阅读，不增加原始计算分辨率。

另一个独立二维截面用于图21，角度和相对材质瓣由`geometry_case()`计算；不是从球图提取的像素，也不是归一化立体角概率密度。图12为面积与方向单位转换的独立几何示例，不参与环境方向表的实际采样。

真实本地查看器：

```sh
python ui.py --port 8080
```

打开`http://127.0.0.1:8080/`，切换四种方法。它读取已经生成的图与JSON，不进行实时GPU渲染。可选截图需要已有Chromium与Playwright：

```sh
python -m pip install playwright
python capture_ui.py --chromium /path/to/chromium
python build_figures.py
```

截图脚本启动正常本地HTTP，使用浏览器默认启动配置，实际切换四种结果并检查解码与横向溢出；不安装浏览器、不改变安全选项。图形生成器执行字体字形、文字边界、重叠、字号、对比、墨迹像素、比例条与实际尺寸检查。字体不存在即报错，不退回缺中文字形的默认字体。精确字节复现还依赖相同字体和浏览器版本。
