# Z变换递推教学模型

代码与自产数值数据采用 CC0；原创图与自制界面截图采用 CC BY 4.0。不包含第三方程序库源码或原课程图件。Canvas检查辅助代码沿用本库此前CC0生成器，数据、构图、正文全部新制作。

## 运行

在本目录使用 Python 3：

```bash
python -m pip install numpy scipy pillow fonttools playwright
python model.py
python build_figures.py
python capture_ui.py
```

`capture_ui.py` 使用已安装的 `/usr/bin/chromium` 默认设置，并启动只绑定本机的临时HTTP服务器。它不会安装浏览器；若系统没有该程序，需按自己的环境和权限准备，或跳过截图。交互查看器可单独运行：

```bash
python ui.py
```

打开终端所示的 `http://127.0.0.1:8111/`。界面是本文的教学应用，不是SciPy官方界面，也没有发布为线上服务。正文静态图已经独立给出全部核心机制。

实际核验环境记录在 `reproduction.json`：Python 3.12.14、NumPy 2.4.6、SciPy 1.17.0；绘图还需Pillow、fontTools和Noto CJK/DejaVu Sans系统字体。字体只用于渲染，不在本包分发。

## 固定输入与算法

- 主规则 `y[n]=a*y[n-1]+b*x[n]`，默认 `a=0.5,b=1,previous=0`。主输入16拍，前两拍为1、2，其余为0。样本单位任意，不是设备测量。循环以一个标量状态处理输入；返回数组另占输出存储。
- 冲激响应由 `0.5**n` 独立生成；两份延迟响应相加核主例。主序列的阶跃公式、非零初始值4的自然响应、正确/错误分块实际执行并断言。
- 双边对照的索引为−5…7：右侧 `0.5**n` 只在n≥0非零；左侧 `-0.5**n` 只在n<0非零。图画有限窗口，正文给出无限序列及不同ROC；不把这组左序列当作同一因果系统。
- 收敛图的权重半径为1、0.5、0.25；记录每项和部分和。它们展示实际条件，不用有限样本证明一般收敛定理。
- 频率响应用257个ω∈[0,π]点计算复数 `1/(1-0.5*exp(-1j*ω))`。余弦实验分别为ω=π/8、3π/4，80拍、零初态；稳态预测是 `Re(H*exp(1j*ω*n))`。正文图显示32…63拍，完整数组仍保存；32拍后最大误差分别约1.51e−10、7.18e−11。
- 稳定性反例a=0.5、1、1.1，分别实际生成16拍冲激和阶跃。短图不证明无穷时间有界；正文另给绝对和与阶跃增长公式。
- SciPy系数b=[1]、a=[1,−0.5]。初态用lfiltic从历史输出4构造；分块在前4拍之后，先用zi=[0]取zf再接续。对于这个一阶转置直接二型，内部状态是反馈系数乘上一输出，不能把任意阶的zi都理解成过去输出本身。
- 随机核验独立生成器 `default_rng(2026102511)`，240次：每次先取a∈[−0.95,0.95)，再取一个正态初值，再取64个正态输入。比较手写递推、SciPy和直接卷积加初始响应。不与其他实验共用随机消费顺序。
- 有限变换核验在z=1、2、i、0.75+0.5i上计算16拍求和、解析无限输出和余尾。求和上限N=15的恒等式为 `Y_N=X_N+a*z^-1*Y_N+a*y[-1]-a*y[N]*z^(-(N+1))`；该主例初态为0。直接求有限和不冒称无限变换。

## 图与数据

`results.json` 是曲线、竖线高度、收敛比、ROC半径、复平面向量、读数的共同输入。固定数学式和布局常量在生成器中，不能把它们当作测量值；轴刻度是显示范围的选择。多系列对比共用坐标，使用不同纵轴的面板明确标注。复平面实虚轴比例相同。

`figure-metadata.json` 记录所有公开PNG的用途、真实尺寸和字号。生成器检查中文/符号字形、边界、文本框、文字重叠、字号、WCAG对比、墨迹像素、竖线值与长度排序。图形语义和文字理解仍需另外逐图审读。真实截图由默认Chromium执行参数、初态和输入切换后恢复主例生成，不由画图程序伪造。

有限测试验证本实现，不能替代一般定理或证明实际设备稳定。代码没有生产级容差、溢出处理、高阶稳健结构、实时性能和安全保证。
