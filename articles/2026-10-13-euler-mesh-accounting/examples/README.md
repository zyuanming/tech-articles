# 原创网格计数与实际 Blender 渲染

代码：MIT（见 LICENSE）。原创网格数据和渲染：CC BY 4.0。无下载、网络请求、硬件控制或第三方模型依赖。

## 核心计数

Python 3.11 或更新版本，标准库。进入本目录：

```sh
python mesh_lab.py
```

覆盖写出 `meshes.json` 与 `results.json`。16个原创模型包括共享ID方盒、不同细分、近似球壳、开口盒、未缝合方片、单/双把手闭壳及两个非流形反例。坐标无单位，只是教学空间。

程序实际通过271项检查：8种方盒细分，100种环面分段，固定种子20261013的150次连续合法细分，10个具体计数案例，3种接缝认同。

`glued_grid` 是组合连接测试，不是嵌入三维的外观模型；接缝会把ID认同，返回的平面坐标不能拿来当接好后的真实几何。用于显示的环面由 `torus` 另行生成。

## 渲染

本篇实际运行版本 Blender 4.3.2、Cycles CPU、48 samples、seed20261013，720×550 PNG。使用已安装的Blender，在本目录执行：

```sh
blender -b --factory-startup --python render_in_blender.py
```

读取原始 `meshes.json`，输出 `rendered/` 下16张图片和 `blender-results.json`。脚本用 Blender 导入后的 `mesh.vertices`、`mesh.edges`、`mesh.polygons` 实际数量与Python计数交叉比较。表面加细黑线仅用于显示，该显示层没有加入网格计数。原始面以多边形保存；渲染器内部的三角化不改变此处说明的原始计数。

这些是原创模型的实际渲染结果，不是实体照片、商业游戏截图或Blender编辑器界面截图。渲染器版本、平台、线程与浮点实现可能影响像素；数值和连接关系以JSON记录为准。

## 能检查什么，不能检查什么

- 边按有序化端点对去重；这里不表示两端相同的多条不同曲线边。
- 面是无内部孔洞的多边形边界；不表示孤立线段、隐藏孔或任意CAD曲面。
- 局部检查包括每边邻面数量、每顶点邻接是否为一个圈/一条路径；不把它称为完整分类器。
- 不检查几何自交、重叠、零面积退化或所有重复面情形；不检查一般可定向性。公式适用性仍需结合对象结构。
- `boundary_loops` 仅当边界邻接图各点度数为2时给出圈数，否则为null。
- V计入输入顶点表所有条目；孤立顶点会被局部检查报出，而不是静默删去。
- `split_edge` 同时更新所有邻面，避免单边T形接缝；`split_face` 以新中心点替换一个面，保留其他连接。

不运行代码也可独立读懂正文。
