# 小车可达性：精确分数实验

模型为一维、无摩擦、每1秒保持恒定加速度的理想小车。位置单位米，速度米每秒，加速度米每二次方秒。没有碰撞、传感器误差、延迟、摩擦或电机内部动态，不用于真实设备控制。

运行：`python reachability_lab.py`。仅需Python标准库；作者用Python 3.12.14实际运行。可加`--output results.json`保存检查结果。

程序用Fraction精确计算，包含一步公式、两步反求、任意初态的无输入漂移修正、精确高斯消元秩、两车共用输入的4状态模型、限幅映射、固定步数最小平方输入。最小平方输入使用该小车终点映射的2×2 Gram矩阵求解，未使用一般约束优化器。最小平方性的解析依据是解位于终点映射的行空间，与所有不改变终点的零空间扰动正交；程序只对一组明确零空间扰动作额外数值验证，不将有限测试冒充对所有系统的证明。

实际检查：6561目标；2401起终点；9841离散命令序列；441限幅输入网格；1089固定步数最小平方输入组合。不同组可能检查相关模型事实，不称完全独立实验次数之和。

GIF由同一个模型按0.1秒间隔生成21帧，命令在t=1变为−1，t=2之后为0。位置按分段恒加速度公式计算，不把不同积分方法混用。GIF播放时长是展示节奏，不用屏幕动画计时验证物理时间。
