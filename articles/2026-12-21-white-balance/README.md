# # 为什么白纸在照片里不是白的

相机只有三个数字，而"白"这件事需要猜。这篇文章从黑体光谱一路走到元激发：色温是什么、白纸在七种光源下的读数差多少、灰世界为什么能把好照片调歪、对角模型的串色为什么补不了、以及为什么完美的白平衡在原理上不存在。所有数字来自 `examples/wb.py`，跑一遍不到一秒。

- 正文：[read.md](read.md)
- 来源与许可：[sources.md](sources.md)
- 审读记录：[review.md](review.md)
- 代码许可：[LICENSE-CODE.txt](LICENSE-CODE.txt)

## 复现

```
python3 examples/run_model.py      # 生成 examples/results.json（约 1 秒）
python3 examples/build_figures.py  # 生成 assets/ 与 cover.png（约 6 秒）
```

`run_model.py` 只用标准库（自写黑体光谱、CIE 1931 配色函数的多瓣高斯拟合、三条假感光曲线、随机反射率场景、四种估白算法、色温最近点搜索、零空间构造）。`build_figures.py` 需要 Pillow（3.14.7 / 12.3.0，见 `examples/run-environment.json`）。两个脚本都是确定性的，重跑得到逐字节相同的图。

## 关于数字

正文和图里的每个数字都由 `examples/wb.py` 算出。几个可以手算复核的：

- 维恩位移：2000 K 的峰值在 2 898 000 / 2000 = 1449 nm，6504 K 在 446 nm。前者落在红外，可见光区只剩长波尾巴。
- 白纸在 2000 K 下三通道读数是 (1.00, 0.44, 0.06)，红蓝比 17.32；10000 K 下是 (0.86, 0.94, 1.00)，红蓝比 0.86。跨了 20 倍。
- 不校正时白纸偏 37.7 度（2000 K），在 8000 K 附近最小，只有 1.5 度，10000 K 又回到 3.7 度。
- 有白纸的场景里，灰世界把 6504 K 下的误差从 5.7 度变成 9.1 度；没白纸时最大 RGB 稳定错 7.6–8.1 度。
- 元激发对：6504 K 下相机三通道差 0.0，2856 K 下差到 9.9%，人眼 uv 距离最大 0.0112，十五对里四对越过 0.004 的 JND。
- 同一个色点，x-y 最近点与 u-v 最近点给出的色温最多差 825 K。

有一处结论是"负面"的，文章没有绕开：在有白纸的场景里，最流行的灰世界算法把误差从 5.7 度放大到 9.1 度，也就是比什么都不做更差。原因是那批色块的平均反射率在蓝通道少了 44%，灰世界把这当成"光源偏黄"去纠正。

`sources.md` 里写明了参考文献、照片许可、每张图的数字来源、模型的简化假设，以及明确没做的事（没有真实相机、没有目视看图）。
