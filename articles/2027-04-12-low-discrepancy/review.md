## 查证线

**这一篇的主轴是「点更顶用换不来确定性」。** 审读时反复问一件事：这一段有没有把「误差有多大」和「你知不知道误差有多大」混在一起。混了就改。

1. **1/√N 不是拟合出来的**：先写理论（二项分布标准差 √(p(1−p)/N)，p = π/4，p(1−p) = 0.168536），再写实测（32 组种子的 RMS）。两处比值 1.076 和 1.029，写进正文，读者能自己用 N 和 p 复算。
2. **斜率手算与拟合两套**：正文先给端点手算（0.48 / 0.674 / 0.769），再给最小二乘（0.490 / 0.689 / 0.783），并说明差值来自「中间点不在直线上」。只给一套数会让读者以为指数是程序吐出来的黑箱。
3. **0.78 的归因**：初稿写「低差异序列对跳变函数只能到 3/4」，那是把实测当定理。改成「实测掉到 0.78 附近」＋定性解释，并在 sources.md 里明确「读者不应把 0.78 当成理论收敛率」。
4. **四倍分子的机制**：初稿写「前 4N 个点常常只是前 N 个点的四份拷贝」——**这是我编的**。写完后去验证：把 256 点集按 1/4 缩回四个子块，没有一个等于 64 点集（命中 0/64）。真实的观察只是「前 N 个点是前 4N 个点的前缀」＋「这 3 对的分子恰好四倍」。整段推翻重写，改成「本稿没有推出来」。这是这一轮最实质的自我纠错。
5. **非单调的发现**：为了给「四倍不动」配一张完整表，把 N 从 32 一直扫到 16384，才发现 8192 → 16384 误差从 8.57e−4 涨到 1.28e−3，以及 64 → 128 也变差。这两处比原来那条「四倍不动」更说明问题，所以正文和图表都补上了。
6. **文献**：Halton 1960（Numer. Math. 2(1):84–90，DOI `10.1007/BF01386213`）、Sobol 1967（USSR Comput. Math. Math. Phys. 7(4):86–112，DOI `10.1016/0041-5553(67)90144-9`）、Cranley–Patterson 1976（SIAM J. Numer. Anal. 13(6):904–914，DOI `10.1137/0713071`）、Kollig–Keller 2002（CGF 21(3):557–563，DOI `10.1111/1467-8659.00706`）四条逐条过了 Crossref 的卷、期、页、年份。
7. **没有原文的出处**：van der Corput 1935 那篇是荷兰语期刊文章，没找到可核的 DOI，也没读全文；正文只写「1935 年由 van der Corput 给出」，不引任何论断，sources.md 说明了这个限度。Koksma–Hlawka 不等式只按名字出现在 sources.md，正文没有写它。
8. **「维度上百优势消失」是常识边界**：本稿只测二维，正文与 sources.md 都明说了未实测。
9. **散布用均值还是 RMS**：初稿只报 RMS，但同一批数均值是 9.87e−3、RMS 是 1.23e−2，差三成。补了一句「报误差时要说清是哪一个」，因为低差异序列的讨论里这个混淆最常见。
