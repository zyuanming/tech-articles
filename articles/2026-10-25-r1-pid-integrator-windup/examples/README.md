## 输入与次序

主模型：tau=5 秒、dt=0.1 秒、Kp=2、Ki=0.5、Kd=0、Tf=0.5 秒、回算 Tt=1 秒、u∈[0,1]，初始 y/I/滤波微分状态均为 0。r 在 t<20 秒为 1.5，此后为 0.4，采样至 60 秒（601 点）。y 为归一化温升，不是直接摄氏温度。三个主试验仅改变抗饱和规则。回算 Tt 敏感性取 0.2/1/5 秒，PID 补充取 Kd=0.5，其余相同。

每拍依次：读取当前 y/r；计算误差和滤波测量微分；用旧 I 得到 v=P+I+D；限幅得 u；由当前误差及 u−v 更新下一拍 I；在保持 u 的采样间隔内用对象解析转移更新 y。I 用显式 Euler，测量微分滤波用 backward Euler，对象转移是恒定输入下的精确解，不能混称整个闭环精确连续解。

条件积分在 `(v≥上限 且 Ki·e>0)` 或 `(v≤下限 且 Ki·e<0)` 时停止积分，其余允许。回算变化率为 `Ki·e+(u−v)/Tt`。正负符号、输出顺序和状态定义不可替换后继续沿用同一结果。

## 输出与验证范围

results.json 保存全部主轨迹、敏感性轨迹、PID 轨迹、手算前三拍、四种方向判断、离散追踪子系统、微分突跳、前馈接点与切换匹配案例。图中折线点、矩形高、比较条长和数值标签从这些输出读取；画布边距/颜色/字号/共轴显示范围是布局常量。

metrics 的 release 是 20 秒之后首次 `u<1−1e−12`，即离开上限，不代表完全离开饱和；另外两种方法在 20 秒仍位于下限 0。settle_02 是从某个采样点起，到本次观察终点 60 秒所有采样均满足 |y−0.4|≤0.02 的最早时刻，不证明 60 秒之后永久保持。iae_after_drop 采用 20 至 59.9 秒的左矩形和，不把终点多算一个间隔。metrics 固定对应本文 20 秒降目标和 0.4 目标；改变模型目标/切换时刻时应同步修改该评估函数，不能直接沿用指标。

已执行的断言：满功率前 20 秒与 `1−exp(−t/5)` 解析解一致；逐拍变化率独立累计与 I 一致；输出范围及 v=P+I+D 一致；不饱和小目标下三种方法完全一致；把目标和执行区间镜像到负方向时三种方法的 y/I/v/u 逐点互为相反数。测试的浮点误差见 results.json/tests。

图 17 是另一个独立标量子系统：P=e=0、外部追踪输入固定 u=1、I 初始为 2。它不是实际 `u=clip(I)` 的闭环。其递推放大因子 `1−dt/Tt` 可演示显式 Euler 的离散限制，但不能证明完整 PID 对象环路的稳定性。图 19、20、21 也分别是独立瞬时/静态反例，不与主模型曲线拼接。

capture_ui.py 用正常 Chromium 和 HTTP 查看全部 3×3×2=18 个选项组合，核参数返回一致、601 样本、u 范围、横向溢出和极值轴标签边界。Tt 在非回算方法中不参与计算；最终截图恢复回算/Tt=1/Kd=0。该程序没有真实硬件连接。
