# 几何实验与原书

运行 `python analyzer_lab.py` 输出完整自检与模型位置。无外部依赖、网络、设备或实物测量。轮盘精确分段、指数反馈和双积分器振荡实验见正文和sources.md。

`shaw-1886-original.pdf` 为1886年公有领域原著的原始下载扫描，来源与权利范围见sources.md；不采用下面的程序许可。
