# RANSAC：可选复现实验

正文：[read.md](read.md)。本文实现非竖直模型 y=ax+b、竖直绝对残差，以及原支持集上的普通最小二乘重拟合。它不是 scikit-image 的正交距离直线模型，也不宣称完全复现任意第三方库。

## 环境与运行

本次 Python 3.12.14、NumPy 2.3.5、Pillow 12.3.0。制图另需 Noto Sans CJK Regular/Bold，脚本开头提供字体路径，可按本机调整。脚本不下载、不安装、不联网。

在本文目录执行，输出目录须为空或不存在：

```sh
python3 examples/simulate.py --out ./my-results
```

输出 results.json（全部轮次、两张支持名单、坐标与结果）、photo-data.npz（照片工作图与亮度差数组）、hashes.json（这两个文件的 SHA-256）。与本次 [expected-results.json](examples/expected-results.json) 核对。随机序列、浮点末位与图像缩放的跨版本逐字节一致性不作保证。

## 合成数据与规则

12 点完整坐标在正文及结果文件中。A–H 由 y=2x+1 加指定小抖动得到，I–L 是四个额外点。算法只获得坐标，不获得这些生成标签。

- 阈值 0.25；使用残差 <= 阈值。
- NumPy default_rng(20261074)，每轮 choice(N,2,replace=False)，12轮；跨轮从完整集合重抽，允许重复点对。
- 该教学种子选来让第二轮为 A、F，不作性能抽样实验。
- x 相同的抽样跳过，仍计一次尝试。本例所有 x 不同。
- 候选排序先支持点数，再支持点内部残差平方和的小者；仍同分保留先到。候选表示、残差和同票规则是本文自己的明确选择。
- 用保存的原支持集做一次最小二乘重拟合；随后重算 mask，只报告，不拿新 mask 继续迭代拟合。

第2轮A、F给出a=2、b=1、8票。最终重拟合a=1.9928571428571429、b=1.0250000000000004；重算后仍8点，成员不变。全点OLS a=1.0919354838709678、b=2.8448924731182794。

结果文件还报告两条拟合线在已知生成内点的8个x位置，相对已知生成线的预测偏差均方根：全点OLS约2.47119989，RANSAC重拟合约0.01636634，单位与y相同。这是合成例子的真值对照，不是照片精度，也不是在支持集内部自我评分。

固定候选 y=2x+1，阈值0.05、0.25、8分别接受2、8、11点。这项对比不重新运行抽样。C、D候选斜率2.2、截距0.5，在0.25阈值下只接受C、D。

## 概率事件的精确口径

12点中8个已知生成内点，一轮无放回抽两个不同索引，28/66=14/33为全生成内点对概率。各轮独立重抽，9轮至少一次抽中约0.9930472446，12轮约0.9986729847。若要达到至少99%的该事件概率，最少9轮。固定总12轮不是动态停止实现。

程序穷举66个无序点对核验28个全生成内点对；其中只有17对在0.25阈值下接受所有8个生成内点。“抽中全内点对”不是“最终正确模型”的概率。真实照片没有逐点真值标签，不计算这一口径的真实内点率、准确率或严格成功保障。

## 实际照片处理

来源：[USGS Bridges](https://www.usgs.gov/media/images/bridges)，Joel M. Galloway / USGS，Public Domain。

[完整原件](originals/usgs-bridges-DSCN0281.jpg)：3240×4320，5,216,398 bytes，SHA-256为3bae50624ad26e6ac520fb3b015fdb8a53854490d9f04d2c13cf9bc669bd0d38。

- Pillow RGB转换，LANCZOS缩小为1080×1440；源图纵横比不变。
- 图像坐标x向右、y向下，左上角像素索引(0,0)。人工ROI为x=100..1049、y=880..999；右/下界写成切片时不包含1050、1000。
- 候选列 np.arange(100,1050,6)，实际最后一列1048，共159列。
- 亮度代理为RGB通道均值；每个候选y的梯度为 abs(gray[y+1,x]-gray[y-1,x])，会读ROI上下各一行作为邻居；没有除2，也不是有物理单位的导数。
- 一列在y=880..999中取梯度最大处；argmax并列取较小y。x=700的最大值位置y=928。
- 阈值3工作图像素、100轮、种子20261014。原支持集内SSE破同票，之后重拟合及重分类，规则同主例。
- 参数在首次试跑前确定，第一次得到的127→131结果保留，没有改ROI/种子/阈值追求更高支持数。

第55轮胜出，原候选a=-0.001851851851851852、b=929.262962962963，127支持点。最终重拟合a=-0.0029604666113119847、b=929.7467749942384。重分类131点，0基候选索引14离开，18、19、22、25、138加入；候选索引按x递增排列。没有继续拟合131点。

全点OLS在该真实输入上a约-0.0060838110、b约930.8568874；没有真实边缘标注，不能把两条线的差别解释成已测得的精度提升。这里只有一幅照片、一个人为ROI、一个简单亮度差算子，局部存在多个平行桥缘以及车辆、树木和阴影。目的在于展示完整输入链和真实限制，不是自动识桥/结构检测/测绘评估。
