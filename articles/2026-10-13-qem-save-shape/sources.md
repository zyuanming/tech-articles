# 来源、视觉职责与复现说明

## 核心范围

本文讲二次误差度量如何为网格简化提供可累加的局部近似成本，以及边折叠、新顶点放置、贪心选择和边界/属性限制。与旧Catmull–Clark细分及BVH文章分别区分“减少几何”“增加细分”“保留几何而加速查询”。

读者前置只需要坐标和平方的最初概念，正文为坐标、面法向、三角形插值补图补解释。矩阵推导集中于可跳读进阶节。实验和练习为可选，不要求安装工具才能读懂文章。

本文使用AI辅助检索、写作、编程、数值核算与原创制图。不存在实物拍摄、历史人物拍摄或真实游戏帧率测试。山地是原创程序模型，Blender图是实际工具渲染而非照片；没有生成或伪造历史图片和工具界面。

## 一手依据

1. Michael Garland、Paul S. Heckbert，[Surface Simplification Using Quadric Error Metrics](https://www.cs.cmu.edu/~garland/Papers/quadrics.pdf)，SIGGRAPH 1997。第3节介绍顶点对收缩与候选对；第4节给出矩阵成本、位置求解与贪心流程；第5节推导归一化平面平方距离及其几何解释；第6节边界和翻面约束、独立质量评价。原文允许非相邻顶点对聚合，本文只实现内部边。原论文奇异位置回退还含线段优化，本例用端点/中点及稳定可解的候选，明确不是逐行复现全部算法。
2. [作者的原始论文与示例页面](https://www.cs.cmu.edu/~garland/quadrics/)。支持两位作者、1997发表、1998颜色纹理扩展、原模型来源和实验软件说明。页面的示例牛、兔、足骨和Crater Lake分别有自己的来源，不从代码许可推导全部模型开放。本篇没有下载或复用其示例模型。
3. [Garland博士论文页面](https://www.cs.cmu.edu/~garland/thesis/)，标明1999年5月9日，Copyright 1999 Michael Garland。用于区分后续系统论述与1997原论文的时间；其网页所述属性与多分辨率章节是进阶指引，不将论文旧机器测速当今日性能。
4. Blender本地实际安装版本4.3.2。实际工具输出由随文render_in_blender.py产生，不通过手绘工具面板假装截图。只用于把已经算好的原创几何渲染成图；没有运行或声称复现Blender Decimate修改器。Blender原程序和名称依其原许可与商标规则，本文并未重新授权软件。

## 真实运行及边界

- 原始21×21顶点高度地形，共441点800面；两座高斯型山峰加一条窄山脊，参数全部公开。坐标无量纲，未从外部模型采样。
- 归一化原始三角形平面，无面积权重；初始Q分别分配给三个顶点，合并时相加。共享平面可重复计入，非“不同平面只计一次”的集合。
- 仅两个端点都不是边界的内部边；锁住80个外边界点。链接条件、投影正面积、旧新法向点积检查及面积阈值按示例代码实施。
- QEM有端点、端点、中点与条件数小于1e10时的解方程候选；不做原论文的线段解析最优化。最短边对照只有中点，因此这是整套策略的比较，不是隔离单个因素的因果实验。
- 采用全局逐轮扫描，未实现堆加速。算法输出320次内部折叠后到160面。400面为241点640边，160面为121点280边，两者V−E+F均为1；输出边界逐点不变，投影总面积4。
- 6561个81×81均匀xy样本，三角形内部按重心坐标插值高度，参照原始800面网格而非连续生成函数。测的是垂直高度偏差，不是Hausdorff距离、所有方向最近距离或全连续域最大偏差。
- 1000次固定种子20261013的矩阵与逐平面平方和恒等检验；平面奇异例和四平面最优位置有断言。示例没有覆盖任意拓扑、脏网格、纹理、蒙皮、GPU或游戏帧率。
- results.json保留Python/NumPy版本、真实耗时、各档网格、检查结果、关键折叠追踪、热图与误差；时间因机器而变，不构成算法竞速结论。
- Blender实际用Cycles CPU、96采样、同一正交相机与灯光，分别渲染原始800面和QEM160面。保留每面平面朝向，没有平滑法线；没有用Blender自身简化器替换教学算法。blender-results.json记录实际版本与导入面数。最终脚本关闭去噪，公开图来自成功完成的实际渲染。
