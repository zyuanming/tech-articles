# 复算PCA的小实验

这是可选补充，正文不依赖运行程序。

## 环境与命令

实际运行环境：Python 3.12.14，NumPy 2.3.5，Pillow 12.3.0。额外交叉检查使用 scikit-learn 1.8.0、`PCA(svd_solver="full")`；主脚本不需要scikit-learn。

在本目录运行：

```sh
python pca_lab.py --out results
```

若保留已有结果，可输出到新目录：

```sh
python pca_lab.py --out fresh-results
```

脚本不访问网络。输入为相邻 `../originals/iris.data` 与 `../originals/usgs-iris-versicolor.jpg`。

## 输入身份

- 四点TOY是原创教学数据，不冒称实测。
- Iris数据来自UCI的原下载包，150行×4数值列，原单位cm，标签不参与拟合。保留`iris.data`原字节。`iris.names`指出第35/38条与Fisher论文存在差异；没有擅自改数。不要直接换成软件内置的修订版再比较最后几位。
- 照片是USGS公开的Iris versicolor照片，权利与署名见[原件说明](../originals/RIGHTS.md)。它不是Iris数据表150株中某株的原始照片。

## 实际输出

`results/results.json`含四点方向/方差/三候选方向、单位变化、标准化、离群点、Iris二维坐标/重建和照片像素选择统计。

图像输出：`photo-resized.png`等比LANCZOS缩图900×702；`photo-mask-45.png`、`photo-mask-180.png`为max(R,G,B)>阈值的白色选区；`photo-axes-45.png`、`photo-axes-180.png`是计算所得两条轴的叠加。线从均值向两端各延伸两倍该方向标准差，线长不是物体尺寸或置信区间。坐标按x向右、y向下；两个阈值分别运行，没有复用旧方向。

程序对每个选中像素位置等权，并未按亮度加权，也未做花瓣识别、物种分类、透视矫正或真实尺寸测量。阈值是本例选择，不是普适分割参数。

## 约定与检查

主方向来自中心化表的SVD，方差采用`s**2/n`总体平均口径。显示方向时令绝对值最大的分量非负，仅为了符号可重复，不代表物理头尾。

独立对照scikit-learn时，核的是方差比例、`n/(n-1)`方差倍率和重建位置，不要求方向符号逐项相同。

程序内15,645条断言使用固定种子20261013：200组随机二维输入检查正交、完整恢复、总平方账、残差账、符号与平移；40组数据各361个角度检查主方差不小于角度网格候选；另核四点手算。有限测试不能替代证明，也不能保证任意病态输入或跨版本末位完全一致。

本文另在干净输出目录重跑，并逐字节比较同环境的JSON和5份PNG。不存在硬件照片采集、植物尺寸实测、游戏引擎测试或人眼识别准确率实验。
