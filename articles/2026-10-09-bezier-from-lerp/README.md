# 鼠标拖的那根“把手”，为什么能拽弯一条线？

正文：[read.md](read.md)。本文用三层线性插值推出二次贝塞尔，说明为什么曲线落在三个点的凸包内、为什么 t 均匀不等于速度均匀，并对照 SVG 的 C/S/Q/T 命令。所有数值都在一个两点的算题上，不是绘图软件的实测。

## 环境与运行

本次 Python 3.15.2，只用标准库。脚本不联网、不下载、不安装。

在本文目录执行，输出目录须为空或不存在：

```sh
python3 examples/casteljau.py --out ./my-results
```

输出 `results.json`，与本次 [expected-results.json](examples/expected-results.json) 核对。脚本末尾的断言会自己失败，不必靠人眼看。

## 数值口径

- 三个点 P₀=(0,0)、P₁=(2,4)、P₂=(6,0)，t=0.5。三层插值得到 A=(1,2)、B=(4,2)、C=(2.5,2)；展开权重 1/4、1/2、1/4 得到同一个点。
- 凸包判定用 101 个均匀 t 的采样点，逐点对三条边做同侧检查；结论是曲线全程在三角形内，控制点本身不必在曲线上。
- t 均匀不等于弧长均匀：0→0.25 的弦长 1.875，0.25→0.5 只有 1.463。
- `Q 2 4 6 0` 与文中三个点同值；这是规范命令与本文坐标的对应，不是某个软件的导出结果。
