# Stable Fluids：可选复现实验

正文在 [read.md](read.md)。不运行代码也能读懂正文。这里用于核对实际计算与原创图的数字。

## 已运行的范围

- Python 3.12.14、NumPy 2.3.5；只重算数值需要这两项。
- 重画图另需 Pillow 12.3.0，以及 Noto Sans CJK Regular/Bold 字体。字体路径写在制图脚本开头，可在自己的环境中修改。
- 原创二维周期 MAC 交错网格，64×64格，区域边长1；没有固体障碍物、墙或自由水面。
- 每步0.04，120步，总模拟时间4.8。长度与时间都是自定的教学单位，不是对某个实物测量所得的米、秒。
- 主运行无持续外力，黏性系数0，染料物理扩散系数0。仍可能出现数值耗散。
- 用一次直线反向欧拉步估来源位置，双线性插值；与1999论文更复杂的轨迹追踪不同。
- 离散散度D、梯度G与泊松算子DG相容，用NumPy FFT直接求解周期泊松问题；q均值取0。q已吸收时间步/密度因子，不输出帕斯卡单位的物理压力。

这不是Stam历史代码的复制、游戏引擎集成或真实空气的工程精度验证。本文程序的数值稳定检查不等于任何平台上的实时帧率承诺。

## 重算

在本说明所在的文章目录运行。输出目录必须为空或不存在，脚本拒绝覆盖非空目录。

```sh
python3 examples/simulate.py --out ./my-results
```

脚本不下载、不安装、不访问网络。它写出：

- results.json：所有121个状态的统计、配置、版本、小算例、断言测试。
- frames.npz：从第0步开始每10步保存一次的速度与染料，共13组，以及第一步投影前后数据。
- hashes.json：本次数值输出文件的SHA-256。

公开的 [expected-results.json](examples/expected-results.json) 保留本文这次运行结果。不同NumPy或FFT实现可能产生末位浮点差异；优先比较数量级、范围及明确误差阈值，不宣称跨平台二进制哈希必然相同。

预期关键数字：

- 第一步投影前散度均方根约0.1423158540，投影后约1.2323×10⁻¹⁵。
- 第0步染料最大值0.9904003，总和167.5071043。
- 第120步染料最大值0.3443014，总和149.0927534。
- 四格校正势按A、B、C、D排列为0、2.5、0.5、2；四条边按A→B、C→D、A→C、B→D排列，从3、1、0、0变为0.5、−0.5、−0.5、0.5。
- 大时间步的单次染料采样保持输入范围；这只是所测插值的有界性检查，不等于轨迹准确。

## 固定输入从哪里来

初始速度由一张称为流函数的辅助标量表构造：横向速度取其纵向相邻差，纵向速度取横向相邻差的相反数。这样计算出的初始离散散度会相消。这里只把它用作可复算的初态，不要求正文读者掌握流函数理论。

辅助表是三团周期高斯函数相加，中心、强度、宽度依次为：

- (0.35,0.48)，0.035，0.095
- (0.65,0.52)，0.035，0.095
- (0.50,0.20)，−0.018，0.09

每团的形式为“强度 × exp(−(dx²+dy²)/(2×宽度²))”，dx和dy取周期区域中的最短有向距离。染料初态按格心坐标计算：

```text
dye = exp(-((y-0.48)/0.035)^2) * exp(-((x-0.5)/0.35)^8)
```

这里的^表示数学乘方；实际Python脚本使用`**`，不是Python按位异或。正文手算的0、4、8、12是另一个独立尺度的小例，不是把这张0到1的染料表截下一角。

主要流程没有随机输入。随机种子20261014只用于额外的投影与采样测试。

## 代码对应哪一步

- sample：按样本位置的偏移，作周期双线性采样。
- advect：对每个新位置查旧来源；分别读取同一份旧u、v，不原地覆盖。
- divergence、gradient、project：相容离散算子、FFT求解及共享边校正。
- diffuse：隐式扩散的周期求解，主运行系数为0。
- run：先扩散速度/投影，再搬运速度/投影，最后搬运染料。外力可在注释指定处加入，主实验未加入。
- small_examples：双线性数值、封闭四格、两格扩散、显式上风反例、恒速平移对比。另含一个一般位置依赖采样不守恒的简单数组例，它不是不可压缩速度场的专门构造；正文守恒讨论依据的是完整二维实测。

数组顺序是[row_y,column_x]，y在数学图中向上；画图时才翻转行以适应图像坐标。u位于(i·h,(j+0.5)·h)，v位于((i+0.5)·h,j·h)，染料和q位于格心，h=1/64。看速度箭头图时，展示的是相邻边速度在格心的平均值并作稀疏抽样，不是把存储位置偷偷改成格心。

## 重画原创图

在同一个文章目录、数值运行完成后：

```sh
python3 examples/build_figures.py --data ./my-results
```

这条命令会覆盖本文章assets中的原创PNG、cover.png和figure-metadata.json；要保留自己的修改，先在文章副本中运行。它不改NASA照片，不使用图像生成模型。

图像全部按固定颜色范围绘制，不逐帧重新拉伸亮度。原始64×64数据以最近邻放大，所以图像像素不代表额外的模拟分辨率。封面取第20步等比放大后的中央区域，不扭曲空间长宽比。
