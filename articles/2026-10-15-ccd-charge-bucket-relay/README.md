# CCD电荷接力：可复算材料

正文：[read.md](read.md)。来源与许可：[sources.md](sources.md)。

这是一个教学记账模型，不是半导体电场求解器、真实相机驱动、CCD性能测试，也没有使用NASA器件的实测像素数据。NASA照片仅用于辨认真实器件。模型无随机数，所有输入与规则公开。

## 运行

环境记录见[run-environment.json](examples/run-environment.json)。数值程序只用Python标准库；绘图另需Pillow和Noto Sans CJK字体。首次制作环境为Python 3.12.14、Pillow 12.3.0；不同字体或Pillow版本可能让PNG像素不同。

在本篇目录中执行：

```sh
python examples/run_model.py
python examples/build_figures.py
```

绘图默认读取Linux字体：

```text
/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc
```

字体collection index为2。若系统没有对应字体，需自行配置受支持的字体路径。程序会覆盖本目录下对应结果文件和原创PNG；建议在副本中运行。NASA照片不会被绘图程序修改。

## 四个独立、范围明确的实验

### 1. 十二个像素的理想读出

输入3×4整数电子矩阵：

```text
100  200  300  400
500  600  700  800
900 1000 1100 1200
```

行从上到下编号0、1、2；列从左到右0..3。先把最下排送入串行寄存器，再向左逐个读空；重复三次。不在读出时继续感光，不含暗电流、容量上限、噪声或转移损失。总电荷7800电子。

预期输出：900、1000、1100、1200、500、600、700、800、100、200、300、400。

文件：

- [readout-events.json](examples/readout-events.json)：初始状态+3并行+12串行，共16个完整状态。
- [readout.csv](examples/readout.csv)：12个输出样本，含事件步、原始行列、电子数。
- 程序每步断言“成像区+寄存器+累计输出=初始总量”，并重建输入矩阵。
- 另外穷举64种二值2×3输入，检验同一算法的顺序、守恒及重建；不是物理器件测试。

### 2. 恒定单步效率的累计模型

[efficiency.csv](examples/efficiency.csv)：2049行，转移次数0..2048，分别计算0.9999^n与0.99999^n。2048步值为0.8148019179981028及0.979728190519641。

每步是一段完整像素间距，不是一个相位子步。这里只跟踪原包按时前进的比例，参数固定，不描述实际陷阱释放、背景依赖或空间差异。图12由CSV直接绘制。

### 3. 守恒的残留拖尾模型

六格寄存器，第3格（零起算）放入1000，左端输出。每拍用旧状态同步计算：

```text
output = eta * old[0]
new[i] = (1-eta)*old[i] + eta*old[i+1]
```

最后一格右邻输入为0。分别运行eta=1和eta=9/10。内部使用Fraction精确算术，检查每一拍累计输出+寄存器残留=1000，再输出浮点显示值。

[trail.csv](examples/trail.csv)保存16拍，图13只画前10拍。eta=0.9是故意放大的教学值。第4、5、6、7拍的非零输出为656.1、262.44、65.61、13.122。小数为平均电荷模型，不是把单个电子切开。模型不是实际陷阱捕获/释放动力学，不适用于仪器校正。

### 4. 定向溢出记账

输入同一列[100,1500,100]，容量1000；人为规定超出容量的量只进入下一行。结果[100,1000,600]，总量1700。没有拟合实际芯片的扩散、势垒、抗溢出漏极或双向流动。

## 图像与数据身份

- 01：NASA网站提供的真实ACS探测器组件照片，原站WebP文件原样保存，1227×1535像素。没有裁切、补画或生成物件。来源页另列更高分辨率版本；本包保留的是页面提供的该尺寸文件，不冒称最高分辨率原摄文件。
- 02—06、09—10、14—15及cover：原创教学示意，不是显微照片、电场求解、真实示波器记录或精确芯片布图。
- 04、05：三相七时刻，0与6时钟状态相同、包位置前移三个栅极即一个像素；相邻包用颜色区分身份。势能台阶为概念图。
- 07、08：实际理想移位模型事件/输出。
- 11：实际执行的定向溢出规则结果。
- 12、13：实际模型数值曲线与脉冲读出。
- [figure-metadata.json](examples/figure-metadata.json)给出15张原创PNG（14正文+封面）的职责、尺寸与最小字号。加上NASA照片，正文有15张独立图。

所有原创图宽1062px，关键文字最小38px，对应354px显示宽度下12.67px。数字序号、刻度、相位标签也包含在检查中。字体大小与离线静态代理不能替代浏览器或平台实际排版检查。

[results.json](examples/results.json)保存汇总、三相状态、ADC及曝光数值例；[model-stdout.txt](originals/model-stdout.txt)是首次实际执行的标准输出。

## 限制与许可

程序没有模拟光子统计、真实掺杂与势能、电子漂移扩散、栅极电压幅值、暗电流、读出噪声、完整饱和动力学或任何特定产品。三相示意不是电路接线建议。部分真实CCD使用两相、四相或多个输出端；本文从简展示不能外推为所有CCD的唯一实现。
