# 提花卡与8根经线：图解复现

正文：[read.md](read.md)。这里提供的是原创解释图与交织组织图生成代码，不是织机动力学仿真、实物织造实验或历史机器CAD。

## 所用环境

Python 3.12.14、Pillow 12.3.0；制图字体为Noto Sans CJK Regular/Bold。字体路径在脚本开头，可按本机调整。代码不下载、不联网、不安装软件。

在文章的副本目录运行：

```sh
python3 examples/build_figures.py
```

会覆盖assets中17张正文图、cover.png和examples/figure-metadata.json。不会改动originals下完整原文件。数字末位和图像字节的跨版本一致性不作保证；照片JPEG使用固定quality=94、subsampling=0，缩放为Pillow LANCZOS。

## 8线模型的明确约定

[model-cards.json](examples/model-cards.json)保存两组教学卡：

- 平纹说明用10101010、01010101交替。
- 小斜纹用11001100、01100110、00110011、10011001，循环两遍。
- 8列对应8根经线，行表示按时间排列的逐次引纬；1表示该次经线位于纬线上，0表示纬线位于经线上。
- 这是单升式上开口、8钩各管1根经线、每纬正常换一张卡的缩减模型。真实针阵列可为二维，卡的定位孔/串卡孔不属于这些8位。
- 组织图的蓝色是已经装好的经线，金色是已经装好的纬线，卡不负责染色。每个格是一个经纬交点，不是直接印到布上的彩色像素。
- 正文一钩三重复的例子另换穿综连接，不能与8钩独立选线的模型混算。
- 所有纬向粗细、线间距、机械偏移和纸厚都是为了说明关系而选取的画法，不对应原机实际尺寸。图中没有计算弹性、摩擦、碰撞、相位或织物强度。

## 机械解释的依据与范围

采用Posselt1888普通单升原理：针尖在左、弹簧在右，卡向右靠近；实部顶针向右并推偏钩，有孔允许针进入卡/卡筒孔。横针眼负责侧向选择，刀架负责向上提钩，连接绳与综眼把选择传到经线。

书中图VIII的连杆在刀架上升时退卡，下降时返回；另一个1909技术来源确认卡必须先退出针尖再分度。本篇只画关键选择状态与卡筒相对位置，没有声称是精确机械动画，也不把一种联动当所有机型唯一时序。双式照片与单升式教学图的身份分开。

真实卡位数说明：书中200针的设计位还可能另带余针。附录第一纬例有200个设计控制位，40线设计重复五次，卡上26×8针位中的另一排为余针。所谓“整张卡决定一次选择”不是“每排孔对应一纬”。见[sources.md](sources.md)的具体页码和原图。
