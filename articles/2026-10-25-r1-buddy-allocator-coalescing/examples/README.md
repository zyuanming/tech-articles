# 复现 Buddy 分配器教学模型

`buddy.py` 是独立编写的串行地址模型，不调用操作系统的页分配器，也不分配真实用户载荷。正文中的 arena、请求量与输出状态都由它计算。Python 3.12 可运行，模型本身只用标准库。

在本目录运行：

```sh
PYTHONDONTWRITEBYTECODE=1 \
  python buddy.py
```

默认重建 `results.json`，包含两条逐步事件序列、向上取整、非零基址反例、两个独立 arena 的失败结果，以及随机交叉检查统计。随机测试单独使用 `random.Random(19019)`；它先初始化 256 字节模型，然后依次执行循环中的分支选择、释放名称选择或请求量选择，没有与其他实验共享随机流。

想把新结果放到仓库以外，可另选输出位置。例如从本目录执行，路径应按自己的目录结构调整：

```sh
python buddy.py \
  --output ../../../../buddy.json
```

重新绘图需要 Pillow、fontTools 和 Noto Sans CJK 中文字体；中文字体缺失会报错。作者验证使用 Pillow 12.3.0、fontTools 4.61.1。绘图读取 `results.json`，不会把旧图作为底图。

```sh
PYTHONDONTWRITEBYTECODE=1 \
  python build_figures.py
```

生成器输出 15 张原创新图并检查文字、像素、边界和元数据。`15-viewer.png` 是实际浏览器截图，生成器不会伪造或重新绘制它；如果截图存在，会把其实际尺寸登记进元数据。要更新截图，先重新运行网页再用浏览器截图。

启动独立的原创教学页面：

```sh
python -m http.server 8000 \
  --bind 127.0.0.1
```

然后在浏览器打开 `http://127.0.0.1:8000/viewer.html`。页面通过 HTTP 读取同目录结果，选择序列并移动滑块即可逐个回放。默认是碎片序列事件 12；手机截图使用 354 CSS 像素视口、3 倍设备像素密度、全页截图，输出宽 1062 像素。状态图中的空闲统计只计空闲表，不计橙色处理中块。

`Buddy.alloc(name, request)` 返回模拟绝对地址或 `None`；`release(name)` 释放同名记录。请求必须为正整数，名称须为未使用的非空字符串，未知名称与重复释放报错。当前字典使用 `popitem()`，在同阶取最后插入块；不承诺最低地址优先。

每个事件同时保存全量块表和各阶空闲表。程序检查覆盖、对齐、不重叠及不留下可立即合并的伙伴；另用逐字节占用数组检查分配成败。全量记录、排序和检查具有额外时间与存储成本，不属于 O(log(N/u)) 抽象分裂/合并路径的常数开销。
