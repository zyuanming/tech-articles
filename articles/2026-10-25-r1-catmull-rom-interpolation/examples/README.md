# Catmull–Rom 可复算教学模型

`model.py` 使用 NumPy，以任意单位二维坐标生成 `results.json`。`build_figures.py` 使用 Pillow、fontTools 与 Noto CJK 字体生成静态图。代码与自产数值数据 CC0；输出图 CC BY 4.0。Canvas 基础检查代码沿用本库此前 CC0 生成器，几何输入、构图与正文均为新制作。

```bash
python -m pip install numpy pillow fonttools
python model.py
python build_figures.py
python ui.py
```

在浏览器打开终端同机的 `http://127.0.0.1:8110/` 查看教学界面；服务只绑定本机，无外部请求。查看器没有发布到线上，也不是商业引擎复现。可选 `capture_ui.py` 需要 Playwright Python 包与系统 `/usr/bin/chromium`，使用默认安全设置，不下载浏览器。安装包和字体需遵循自身系统环境的权限。

已运行环境：Python 3.12.14，NumPy/Pillow/fontTools 的实际版本记录于 `reproduction.json`；界面截图浏览器 Chromium 154.0.8037.57。

## 输入、算法与范围

- 贯穿主例 `[(0,0),(1,2),(4,3),(6,0)]`，依次计算 α=0、0.5、1；每段401个显示采样点，曲线本身由三次多项式定义。
- `segment` 以相邻距离幂生成结点，用非均匀加权差分产生全局导数，再乘当前段间隔得到局部导数。均匀时直接使用间隔1，不对0作0次幂。
- `pyramid` 是单独实现的 Barry–Goldman 三层线性插值/外推，作为求值交叉核验，不调用 Hermite 求值函数。
- `chain` 为开放路径线性外推首尾虚拟点。非均匀参数拒绝相邻完全重复点；未实现闭环、近重复容差、全局碰撞检测、机器人动力学或产品性能优化。
- `crossing` 对二维三次多项式 `a u³+b u²+c u+d` 求两个不同参数的交点。除去 `(u−v)` 后，令 `s=u+v`、`z=u²+uv+v²`，解 `a z+b s+c=0`，再用 `uv=s²−z` 解出 u、v。奇异矩阵返回无结果，不能把这个分支理解成一般性的“绝无交点”判定器。
- 为获得清晰反例，单独随机生成器种子20261025在每个坐标整数−10至10间取四点；跳过相邻重复点；筛选参数差>0.3、环的横纵跨度均>0.12、交点两切线夹角在25°至155°之间。第1363组满足条件，公开结果中的 `loop.selection` 记录规则。选中的整数输入在正文完整给出，不声称此频率代表一般曲线。
- 另一独立随机生成器种子71025产生180组高斯分布输入：α=0、0.5、1各60组，每组顺序核u=0、0.17、0.5、0.83、1。每组另在u=.37以步长1e-6核验中心差分导数。两实验没有共用随机状态。
- 全路径交点用明确公开的对称点集，对第二/第四段从(.5,.5)起做12次二维 Newton 迭代；记录两参数位于(0,1)及代回残差，不泛化成鲁棒路径相交算法。
- 弧长表为4001点折线累计长，以线性反查得到11个位置。图上比较的是相邻位置弦长，不冒称精确弧长或严格恒速。

## 数据、图形与复验

`results.json` 包含控制点、结点、斜率、局部/全局导数、三次系数、贝塞尔控制点、所有曲线采样、递归层、交点、速度比较与测试误差。图中的位置、曲线、向量、结点轴长度、数字标签由此驱动；基函数图以其中同一u网格执行正文给出的基函数定义。图的边距/字号/配色属于版式常量，不是测量结果。

`build_figures.py` 对中文cmap、文字范围、文字重叠、字号、字形墨迹、画布尺寸作断言；所有平面图以相等x/y比例变换。曲线比较同输入、同轴、同尺度；回环局部放大明确给出不同坐标范围。控制多边形是灰线，曲线身份由图中文字逐一说明。图20前两层同一坐标，第三层明确放大展示结果，第一层延长线不是额外曲线段。

`figure-metadata.json` 记录每张公开图片的用途、尺寸与字号。`capture_ui.py` 实际切换参数并检查结果变化，再恢复均匀主例截图；截图不能替代全站浏览器检查。

所有有限测试只核验本教学实现。理论保证来自正文引用的一手文献，测试没有证明向心参数化定理。
