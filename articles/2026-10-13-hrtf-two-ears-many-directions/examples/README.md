# 可选复算与试听

主文的静态图文可以独立阅读。这里不要求运行浏览器音频算法；五个音频文件已经由Python生成。

## 运行

使用Python 3和NumPy。本文实际环境为Python 3.12.14、NumPy 2.3.5。

```sh
python audio_lab.py
```

从任意工作目录运行均可，脚本按自身位置寻找上一级originals中的四个响应文件，覆盖本目录的results.json和dry/front/right/back/up40.wav。它不访问网络，不录音，不读取用户账户或其他目录。

若没有NumPy，可以直接阅读代码与已有结果，不必安装才能理解文章。

## 文件对应

- [dry.wav](dry.wav)：原创合成噪声短音，左右相同，尚未做方向滤波。
- [front.wav](front.wav)：方位0°、仰角0°。
- [right.wav](right.wav)：方位90°、仰角0°。
- [back.wav](back.wav)：方位180°、仰角0°。
- [up40.wav](up40.wav)：方位0°、仰角40°。
- [试听页面](listen.html)：手动点击播放，默认不自动播放、不预加载完整音频。

所有音频44100 Hz、双声道、16位PCM。输入用固定随机种子20261013生成90毫秒Hann窗噪声，分别放在0.2、0.65、1.1、1.55秒起点。干声2秒；完整卷积输出每声道88327样本，约2.00288秒。所有文件两个声道使用同一个整体增益，不单独拉大某只耳。

使用耳机时选择较低且舒适的音量，不要为了听出方位持续加大音量。音频不是听力测试；听不清前后不代表听力异常。通用假人数据与个人耳形、耳机未做个性化匹配，也没有连续头部追踪或房间模拟。

## 程序确实检查了什么

1. 四个响应的声道数、采样率、位深、样本数。
2. 单位脉冲卷积复制响应，手算[1,2,0]与[1,0.5]得到[1,2.5,1,0]。
3. 800组固定种子随机短数组，双循环定义对照NumPy卷积。
4. 输出写回并重读WAV，检查帧数、声道、采样率、半个量化步以内的舍入误差及数字幅度不削顶。

结果见[results.json](results.json)。这些是数值与文件检查，没有声称主观听辨实验通过。
