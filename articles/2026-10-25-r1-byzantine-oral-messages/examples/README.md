# 口信算法教学仿真

这些程序是Python同步模型，没有真实节点、网络或延迟测量。代码及自产JSON采用[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)，生成的原创图片和教学报告截图采用CC BY 4.0。已用Python 3.12.14运行。

从本目录运行，仿真本身只需Python标准库：

```sh
PYTHONDONTWRITEBYTECODE=1 python run_examples.py
```

`om.py`实现递归OM(m)。`run_examples.py`产生`results.json`：包含全部消息槽、原始内容、默认值归一、逐接收者归约、固定主例、有限验证结果。事件先按子问题递归生成，再按轮次/路径/接收者排序；不把这种排序当作真实并发时序。每个来源路径只含不同节点，OM(0)直发后停止；接收者自己的来源列使用直收值。

输入成员顺序四人为C,A,B,D，七人为C,A,B,D,E,F,G。值域为“进”“退”，缺报为None；其他无效值也归一为退。无严格多数时退。坏发送者控制自己的有效发送槽，不能冒充直接发送者或改变忠诚者信道。重复/越界路径或额外消息不属于本模型有效槽；生产中的消息解析和抗滥用防护不在此仿真内。

固定案例：坏C给A进，其余退；好C给所有人进，坏D给A退、给B进；缺报例坏C不给D发送。七人例中C给A/B/E进，给D/F/G退，坏B向成员索引为奇数的接收者发送进、偶数发送退（索引从0开始）。坏节点自身的计算输出只供追踪，性质断言只比较忠诚副官。

四人验证覆盖两种无故障输入，以及一个坏节点所有有效槽的进/退/缺报选择，共83组；坏C的名义输入不影响性质，因此只枚举一次。七人100组各用独立种子20261025…20261124；每组先抽样两个坏节点，再抽样指挥官命令，最后按照完整无故障事件列表的“轮次、路径、接收者”顺序，为坏发送者逐槽抽样进/退/None。没有跨组共享随机生成器。此有限测试不构成任意攻击证明。

`slots`是预期消息槽数，`sent`是raw非None的发送数。固定n4和n7正常例的槽数为9与156；缺报例slots=9而sent=8。数据里的三人例故意不满足人数门槛，记录有效性失败。worlds是三个不可区分情形的初始消息投影视图，其值是场景输入，局部视图比较由代码计算；不能把该表当作对任意协议的穷举证明。

绘图需Pillow与fonttools，以及系统Noto CJK/DejaVu字体：

```sh
PYTHONDONTWRITEBYTECODE=1 python build_figures.py
```

`figure_canvas.py`复用本库CC0绘图检查工具的API；本文全部构图、文字和数据新制。画布1062像素宽，文字不少于40像素；检查字体cmap、文字出界/越框/互相重叠、对比度、墨迹和输出尺寸。几何检查不能替代目视检查箭头与字符的位置。

真实只读报告使用`report.html`读取JSON。在本目录启动本地HTTP服务器：

```sh
python -m http.server 8166 --bind 127.0.0.1
```

在另一个终端从本目录运行（需Playwright和系统Chromium）：

```sh
PYTHONDONTWRITEBYTECODE=1 python capture_report.py \
  --audit-dir ../../../../oral-messages-audit
```

审计目录示例位于仓库外，按本地目录位置调整。截图使用默认系统Chromium，不使用安全覆盖；验证1062/354宽度和实际报告数值。`figure-metadata.json`记录每张图身份、用途、尺寸与检查；手机排版代理、浏览器检查日志不属于公开文章材料。每次重新生成绘图后，再运行截图脚本补回截图元数据。
