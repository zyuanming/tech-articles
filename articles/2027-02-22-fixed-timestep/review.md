## 两个实验设计上的返工

**其一，`spiral` 一开始会死循环。** 递推是「每帧步数由累加器决定、步数又决定这一帧耗时」，当 `cost ≥ fixed` 时每帧补的步数永远追不上，帧时间单调上涨，`while` 没有出口，跑 25 ms 那一档时脚本直接挂住。改成每档最多 5000 步、且仿真时间落后墙面时间超过 5000 ms 就判 `diverged = True` 并停。这个「发散」标志就是正文里「c = 18 时 60 帧内就冲到 5.4 秒」的来源。

**其二，`tunnel_rate` 初版恒为 0。** 第一版按「这一步首尾两个位置是否跨过墙面」判，但采样是在整段位移上均匀取点，第一个采样点几乎总落在墙左边、最后一个总落在墙右边，判定条件写反了符号，200 次试验全部返回 0.0。改成「先加一步、再检查是否落进 [lo, hi] 区间」之后才和闭式曲线对上（0.385 / 0.675 / 0.840 对 0.85 的闭式）。这个 bug 是`results.json` 里那一列全是 0 暴露的——如果只看图，那会是一张只有横轴的空白图。
