# 差分制表教学模型

Python 3.12+。`run_examples.py` 使用标准库与精确整数，从多项式直接生成差分初值，再用独立递推核对。没有随机输入、浮点舍入、真实设备计时或机械动作仿真。

生成器会写回本目录的结果与图片。若只为审核复算，请先将整篇文章复制到仓库外的审核目录，再在副本的examples目录执行，避免改动原件。

在副本的本目录执行：

```sh
PYTHONDONTWRITEBYTECODE=1 \
python run_examples.py
```

它重建 `results.json`：主例 y(n)=n³+2n+1、0至12的整数输入、逐次写回、反向写回错误、73+63的三位进位、748+273的三位溢出反例、三阶初值多一的误差、步长改成2和指数数列边界。

另外核验起点−20至20、步长1至5的205组情况，每组连续30个值，共6150个结果。此有限核验为实现检查；一般正确性的理由在正文的代数推导。

绘图需要 Pillow 与 fonttools，并需要生成器候选列表中的 Noto Sans CJK 字体：

```sh
PYTHONDONTWRITEBYTECODE=1 \
python build_figures.py
```

生成器读取 `results.json`，输出11张原创教学PNG及 `figure-metadata.json`。全图宽1062像素，关键文字不小于40像素；检查字形、出界、越框、文字重叠、对比、墨迹和实际尺寸。图的逻辑、箭头语义及可理解性仍需人工审读。三位数列布局和逐位加法是数学教学模型，不是巴贝奇历史机械的尺寸、传动或动作时序。
