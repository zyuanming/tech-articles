# 重算 Theseus 教学模型

这是原创离散教学程序，提取 Shannon 报告里的方向记忆、旋转尝试、目标策略与计数切换。它不是原始继电器线路仿真，也不是原机测试。代码 MIT，署名 zyuanming，见 [完整许可](../LICENSE-CODE.txt)。

## 运行

从本文目录执行，模型只需 Python 标准库：

```bash
python examples/run_model.py
```

实际运行环境记录在 [run-environment.json](run-environment.json)。已使用 Python 3.12.14。无需随机种子，程序无随机性。

重绘原创图片还需要 Pillow 12.3.0，以及 Noto Sans CJK Regular/Bold TTC 字体。脚本使用安装在 `/usr/share/fonts/opentype/noto/` 的字体，face index 2；其他系统可修改两个字体路径，但像素不一定逐字节相同。

```bash
python examples/build_figures.py
```

Pillow 与字体是运行依赖，未包含在 MIT 授权的原创代码中；Pillow 与字体本身各依原许可。本目录不下载、安装或运行第三方代码。图片生成脚本不会获取或改动第三方肖像。

## 坐标、方向、墙

九格行优先排列为 A B C / D E F / G H I。row 向南增加，col 向东增加；N/E/S/W 分别编码 0/1/2/3。边无向，只有上下左右相邻格能相连。

开放边为 AB、BC、AD、DE、DG、EF、EH、FI、HI、CF。未列出的相邻边和外边界都是墙。起点 A，目标 C，初始方向全 W。改墙只移除 CF，不动其他边。

## 明确的模型约定

- 入格后，探索模式先将本格旧方向逆时针转 90°。
- 把报告的“当前访问的进入方向”解释为通向上一格的回头边，仅在本次入格的第一候选上跳过它；碰墙后继续旋转时不重复跳过。
- 每次方向尝试都更新本格记忆。成功跨格记录 move；失败尝试连同退回中心记录 wall。
- 目标模式首先尝试旧方向，不先旋转。碰墙后继续逆时针转，不立刻改为探索。
- 每次重置起点不更改记忆；无须把探索路线作为决策输入。日志 path 仅供结果输出，决策不读取它。
- 计数只计成功跨格，不计撞墙回中心；九格门槛取 8，未到目标才切换。先检测目标，再检测超时。
- 切换只改变策略，不清空记忆。本约定不声称复刻原机保持/复位线路的每一项动作。
- 孤立格尝试四个方向都失败时，本模型返回未到达；不模拟真实装置无限重试。
- max_moves 是程序观察上限，不是历史硬件部件。不切换案例取 24 次，专门展示仍在循环的截断记录。

原报告是口头演示和问答记录，不是完整的触点/电机时序规范。上述离散化和初值属于本教学实验，不能用输出反向证明原机恰好走同样路线。

## 输出

- [results.json](results.json)：完整输入、五组运行、每格最终记忆、逐事件记录与有限枚举结果。
- [events.csv](events.csv)：同样事件的平面表。wall 的 move 值为当时已完成跨格数，move 事件为这次跨格后的累计数。switch 不包含 direction 等不适用字段。
- [figure-metadata.json](figure-metadata.json)：原创图尺寸与文字边界。38 px 在 1062→354 缩放后为 12.67 px；这是尺寸核算，不是平台实际预览结果。
- [model-stdout.txt](../originals/model-stdout.txt)：一次真实运行摘要。

应得到首次 8 次跨格/6 次碰墙，重跑 6/0，从 B 开始 7/0，改墙不切换 24/1（未到达），改墙切换 14/7（到达）。短路比较是 A-B-C，两次跨格。

## 检查范围

程序验证首次手算轨迹、各已访问格的最后出口、无墙改变时的无环重放、一次门槛切换与改墙重学。广度优先搜索只作独立最短路尺子，不参与模拟决策。

另外枚举 2×2 四格中、从 A 开始、首次到 D 即停、长度最多 8 条边的 30 条行走，核对最终出口的严格时间递增性质。

最后枚举 3×3 网格 12 条潜在无向边的 2^12=4096 个子集。1494 个子集能从 A 到 C；统一全西初值下全都到达，探索最长 20 次跨格，并检查最终重放至多 8 次跨格。这不是全部初始状态、所有规模或原硬件的验证。
