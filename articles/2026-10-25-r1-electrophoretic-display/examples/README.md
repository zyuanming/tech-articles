# 电泳显示的教学计算

这是匀场漂移、位置裁剪与能量记账的教学模型，没有连接真实面板。它不能预测灰度、残影大小、刷新波形、保持时间或温度性能。

使用Python 3.12及Pillow、fontTools，系统需安装Noto Sans CJK中文字体。在本目录运行：

```sh
PYTHONDONTWRITEBYTECODE=1 \
python run_examples.py
PYTHONDONTWRITEBYTECODE=1 \
python build_figures.py
```

第一步写出results.json；第二步依据JSON生成14张原创PNG和全部19图的figure-metadata.json。第三方实拍原件不重生成、不调整像素。建议复制整篇目录到独立位置复算，以保留下载版本原字节；字体及库版本改变可能影响PNG字节。本文使用Pillow12.3与fontTools，图义和数值不依赖PNG压缩字节一致。

模型参数：电极间距30µm、正电颗粒的有效迁移率2e-10m²/(V·s)，电压相对观看侧公共电极；速度v=µV/d。位置p=高度/d，更新p后截断到[0,1]。p不是灰度。负电颗粒在同一电场下反向；演算只追踪正电黑颗粒，以免将两类独立轨迹误称真实密集悬浮液仿真。

零伏秒反例采用先+15V、后−15V、各0.30秒，从p=0.2出发。因边界裁剪，最后到0；未实现生产驱动中的直流平衡、颗粒相互作用或光学计算。

能量模型假设每次额外更新12mJ、持续基线20µW、3600秒观察，更新项不重复包含基线，总量为两项之和；不含前照灯、无线及CPU活动，不能当照片设备的规格。

所有计算确定性、无随机输入。生成器检查中文字符存在、文字出界/越框/重叠、字号、对比度、墨迹与实际尺寸；定量长度和曲线从JSON生成。这些几何检查不能代替物理和阅读审查。
