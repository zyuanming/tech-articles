# 二叉堆实验

仅需 Python 3 标准库；实际核查版本为 Python 3.12.14。本文代码为原创教学代码，按本文 CC BY 4.0 许可提供，不是 Python 标准库实现的复制。代码不访问网络，不安装包，不改用户环境。

运行：

```sh
python heap_lab.py --out results.json
```

输出包括七数建堆、插入2、弹出2的逐次交换，降序输入两种建堆方法的键比较次数、平局顺序反例、事件模拟结果及测试范围。若任何断言失败，程序不会报告 PASS。

- 比较计数仅包含 `MinHeap.less` 内对键的 `<` 比较；循环判断、数组下标计算、测试检查与 Python 内部操作不计。
- `MinHeap` 假定比较构成一致全序，实验输入为整数及相应元组。不支持 NaN 或不经修复就从外部变动的优先值。
- 状态轨迹用于小例子教学；混合测试按步清空轨迹，生产使用应移除计数/轨迹而不是照抄为通用容器。
- `IndexedHeap` 使用 `(priority, integer_id)` 作为比较键，平局按 ID 排，未承诺先来先出；每次交换更新 ID→下标。
- `LazyQueue` 更新时分配新序号，旧版本留在物理堆里；`rebuild` 从有效条目构建新堆。它没有自动重建阈值。
- 模拟时间为整数绝对秒；用版本计数确定平局，不调用 sleep，不测真实游戏性能。

有限测试不是正确性或复杂度的完整证明；原理在正文展开。算法输入状态是确定性的；混合测试种子为 1964000 至 1964019（每个2000步），索引堆种子为 245000 至 245009（每个2000步）。
