# 两只寄存器的小实验

使用Python 3运行 `python register_lab.py`。程序仅使用标准库，将测试结果和示例轨迹打印成JSON，不接触网络，也不生成可执行机器码。

三种代码各自回答不同问题：
- `liveness` / `interference` 只处理本文这类固定直线程序，示例没有变量到变量的复制。
- `simplify` 在度数条件不足时会返回None；这只表示该充分条件卡住，不是不可着色证明。
- `exact` 只供这些小图交叉核验。它是指数回溯，不建议用于大型程序。
- `spilled` 是专门写出的两寄存器教学改写，并不是通用spill生成器；它允许一个内存源参与加法。

所有输入源在相应input指令才读取，算术先读完源操作数再写目标，整数没有固定机器位宽。测试结果不表示生产编译器正确性或硬件性能。

末尾练习提示：如果返回e+a，a必须一直保留到末尾，主例子的原着色会破坏a；四环增加一条对角线后出现三角形，两色不够。改变spill候选时，要检查完整改写的可执行性与所有内存访问，而不仅是删掉图上的一个节点。
