# SSA教学实验

运行：`python ssa_lab.py`，可加`--output results.json`。仅使用Python标准库，作者在Python3.12.14实际运行。

## 这里实现了什么

- 原创的小型整数中间表示：基本块、copy/add/mul/lt、条件分支、跳转、返回和phi。
- 按前驱选择phi输入；同一块全部phi先读取、再一起提交。循环允许同一静态定义点反复执行。
- 唯一定义、已定义使用、普通使用的支配关系、phi输入的前驱边可用性，以及phi来边完整性检查。
- 固定点集合交计算支配关系；按定义计算支配边界。不是1991论文的快速SSA构造算法，也没有实现从任意源程序自动生成SSA的前端。
- 保守常量传播：只在所有phi来值都已知而且相同时，得出phi为常量；不分析不可执行边，所以不是完整SCCP。常量替换保留CFG和定义结构，并不演示死代码删除或代码生成。

输入使用Python无界整数，条件以0为假、非0为真。没有固定宽整数溢出、内存、指针、异常、并发或外部副作用。`validate`面向本稿列出的教学IR，不是面向不可信输入的安全沙箱；它拒绝不可达块和入口回边，也不是LLVM verifier替代品。运行有10000基本块预算，超预算明确报错，不把预算耗尽解释成数学上的不终止。

## 实际检查范围

- left/right/extra各取−8至8，flag取0/1，共9826个输入；原始与常量替换程序都同直接分支计算一致。
- n取−10至300，共311个求和循环例，与Python `sum(range(n))`一致。负n与0都不进入循环体。
- 初始a、b各取−4至4，n取0至20，共1701例交换循环，与直接同时交换一致。返回值用1000*a+b编码；此范围内两项有足够间隔区分，非一般二元组序列化方案。
- 固定种子199110，2000个有2至10块、含入口链与额外边的小CFG；用“删除候选支配点后重新走图”的方法，独立验证所有支配关系。
- 3个故意非法程序：重复定义、漏phi前驱、非支配普通使用，均被拒绝。
- 两边均7再加2：返回9，解释器路径中的算术操作数从1变0。不是LLVM/CPU性能测量。
