## 查证线

正文里的那段 Python 被原样抽出来跑过（仓库 venv，标准库），输出依次是

```
0 ('200', 'v1')
20 ('local', 'v1')
70 ('200', 'v2')
131 ('304', 'v2')
```

与第 9 节写的「第 0 秒 200、v1；第 20 秒 local、v1；第 70 秒 200、v2；第 131 秒 304、v2」逐项一致。这段只在本地模拟新鲜期与 ETag 两条分支，没有联网，也没有假装是某款浏览器的真实实现。

其余能核对的：

- `Cache-Control: max-age=60`、`s-maxage=300`、`ETag` / `If-None-Match`、`Vary` 这几个头的写法照 RFC 9111、RFC 9110 的字段名照抄，没有自造字段。
- 200 与 304 的分工按 RFC 9111 的描述写：304 表示「你手上的这份仍然有效」，正文特别指出它没有把内容换回旧版。
- `immutable` 指令与带版本 URL 的配合按 RFC 8246 写；正文没有声称某个浏览器一定按这个头执行。

`sources.md` 里 RFC 9111、RFC 9110 15.4.5、MDN 缓存指南、RFC 8246 四个链接都是原站页面。
