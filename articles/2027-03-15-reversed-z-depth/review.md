## 这一份是什么

《深度缓冲只记得住 48 厘米》的独立审读记录。审读对象是 `read.md`：

审读方式：同一个 AI 助手写完初稿后重做一遍检查，独立性有限——它知道自己原本想说什么，所以对「第一遍读会不会跟丢」的判断不如陌生人可靠。能用重跑或抓原文验证的都做了；只能靠人眼看的，见最后一节。

## 查证线

**1. 每个数字回到 `results.json`。** 逐项对过：`depth_values`（1 / 10 / 100 / 500 米的 0.90009 / 0.990099 / 0.9990999 / 0.9999）；`steps`（六个距离上 `fixed24` 与 `f32_std` 逐项相同，900 米处 0.4827495875；`f32_rev` 为 7.4498e-8 / 9.312e-7 / 5.8202e-6 / 1.81881e-5 / 1.81881e-5 / 7.3662e-6）；`near_sweep`（11 档，0.05 → 298.0083 毫米，100 → 0.1341 毫米）；`far_sweep`（600 米 0.148987 到 100 万米 0.149012）；`collapse`（20000 点，66 / 66 / 0，`merged_z` 的 795.05 / 927.25 / 999.08）；`threshold`（1 毫米 41.0 / 57.9 / 129.5，1 厘米 129.5 / 183.2 / 409.6，10 厘米 409.6 / 579.3 / 999，1 米全 999）；`threshold_near`（1 厘米、near 0.1 / 1 / 10 → 129.5 / 409.8 / 999）；`rev_worst`（587.29 米处 2.509e-5）；`subtract_after`（`trap` 834、`matrix` 0，掩码和 834）；`premultiply`（0.5 米 495 / 0 与 487 / 0，0.2 米 409 / 216 与 737 / 0，0.05 米 563 / 191 与 922 / 0，反转三档全 0 / 0）。正文里没有出现 `results.json` 里查不到的数。

**2. 八处手算复核。** 其一，`f/(f−n) = 1000/999.9 = 1.0001`，z = 1 给 `1.0001 × 0.9 = 0.90009`。其二，`(f−n)/(n·f) = 999.9/100 = 9.999`，乘 2 的 −24 次方得 5.96e-7，z = 900 给 0.4828（模型 0.48275）。其三，float32 在 [0.5, 1) 的间距是 2 的 −24 次方，与 24 位定点同值。其四，far 只出现在 `(f−n)/(n·f)` 里，f 一大趋近 1/n。其五，near 反比：148.997 毫米 ÷ 10 = 14.8997，模型 14.8863（差在 f−n 也动了）。其六，`5.96e-7 z² = 0.01` 给 z² ≈ 16778、z ≈ 129.5；`z_half` = 129.53 × √2 = 183.19。其七，900 米处 30 厘米的间隙：`1 − 0.3/0.48275 = 0.3786`，与 `merge_prob(900, 0.3, …)` 的 0.37856 一致。其八，`0.48275 / 7.3662e-6 = 65533`，正文写「六万五千倍」。

**3. 两条 DOI 用 Crossref 核过卷期页码。** Upchurch & Desbrun, *Tightening the Precision of Perspective Rendering*, Journal of Graphics Tools 16(1):40–56, 2012（`10.1080/2151237x.2012.649987`）；Lapidous & Jiao, *Optimal depth buffer for low-cost graphics hardware*, HWWS '99, 67–73（`10.1145/311534.311579`）。标题、卷期、页码、年份四项都对上，正文只用了年份与结论，没有引用页码。

**4. 两个网页是真抓下来读过正文的。** Nathan Reed《Depth Precision Visualized》（2015-07-03）的静态 HTML 21 760 字节，正文里「d 是 1/z 的线性重映射」「1/z 在屏幕空间线性（引 Emil Persson 的笔记）」「反转 Z 让 float 缓冲基本零错误」「分离 view 与 projection 会把颠倒换成合并」「far 几乎无影响」都能在原文里找到对应句；NVIDIA 转载页 54 777 字节，数字与上一条一致。正文第七节关于 Lapidous–Jiao 与 Upchurch–Desbrun 的分工是按这两篇的摘要写的，没有引用具体页码。Persson 的原页我没有抓，正文只写「Reed 引了它」，`sources.md` 里也标了这一点。

**5. 复现。** `run_model.py` 连跑两次，`results.json` 的 md5 都是 `512a7b9be288b603523494249d6b5bf4`（46 716 字节，约 0.21 秒），`selfcheck` 为 true。`build_figures.py` 约 3.5 秒，12 张图与封面重出。全程无随机数：float32 舍入用 `struct.pack('<f', …)`，定点量化用整数放大，同一台机器上重跑逐字节相同。

**6. 图文一致性。** 12 处引用、12 个文件，编号 01 → 12 严格递增，无缺失、无多余。全部 1062 px 宽；封面 1080×1080、117 228 字节。`figure-metadata.json` 里 `min_label_px` 只有 38 与 40，`effective_min_at_354px` 最小 12.67，12 张全部通过 `figkit.verify()` 的 `TEXT_OVERLAP` / `OFFCANVAS` / `NOT_INSIDE` / 对比度 / `BOTTOM_GAP` / `WIDTH_COVERAGE`。纯 PIL 统计的非背景像素占比 8.4%（图 07）到 38.9%（图 10），没有空白图——图 10 是两块 50×20 的掩码，面积大属正常。

**7. 标点与引号。** 正文里出现的半角符号只在公式、行内代码和区间记号里（`(f−n)/(n·f)`、`[0.5, 1)`、`[0,1]`）。叙述用的逗号、冒号、括号都是全角。「」15 对全部闭合，没有用到『』，没有直引号。

**8. 一个被推翻的阈值定义。** 初版 `threshold_distance` 做的是「二分找最后一个还能分开的距离」，`near = 0.1`、1 厘米时给 185.9 米。这个数不能用：格距在 129.5 米就已经超过 1 厘米，185.9 米处两个面还能分开纯属相位凑巧（正好跨在格边两侧），换一对同间距的面就合并了。现在改成三档：格距 = 间隙（保证界限）、格距 = 2 × 间隙（一半合并）、格距 = 10 × 间隙（九成合并），图 9 也随之从柱状图改成四条合并比例曲线。正文里那个 186 米被换成了 129.5 / 183.2 / 409.6 三个含义明确的数。

**9. 首页自洽。** 开头那对墙差 30 厘米、900 米处格距 48 厘米，所以「有时算得出来、有时落在同一格」——比例是 0.3786，第九节给了同一个数，两处不矛盾。第二节的「1677 万个格子」是 2 的 24 次方，与 `q_fixed` 的 `bits=24` 一致。第十二节表里「错的对子从 625 变成 737」是我把 409 + 216 与 737 + 0 相加得到的，正文写「多了 18%」，737 / 625 = 1.179。

## 没做的

**`VISUAL_REVIEW_NOT_RUN`**：12 张图与封面没有经过人眼复核。当前模型不能看图，只能靠 `figkit` 的几何断言（不出画布、不互相压、字号换算到 354 px 后不小于 12 px）和纯 PIL 的颜色区域统计（有没有空白图、每张的非背景占比）来间接确认。曲线是否「看着舒服」、锯齿画得是否明显、图 10 的两块掩码是否一眼能看出红在哪一段，这些都没验证。

其余没做的：

- **没有在真实 GPU 上跑。** 全文没有帧率、带宽、填充率；所有结论都是「量化后的深度值是否相等」，不含视口变换、光栅化与深度测试的实现细节。
- **没有测 MSAA、深度压缩、layered depth。** 这三样都会改变「相邻两面能不能分开」的实际表现，模型没有覆盖。
- **没有比较对数深度缓冲。** 它是另一条路，正文没有做取舍分析，也没有实验。
- **没有做二阶误差。** `merge_prob` 用 1 − 间隙/格距 这个几何近似，没有把「两个面各自被投影矩阵舍入一次」算进去，所以图 9 的斜坡是理想化的。
- **没有分层看「事后减 1」的失败。** 第十一节只给 834 / 1000 这一个总数，没有按距离分段看哪一段最惨。
- **没有把 `far` 拉到 near 附近做压力测试。** `far_sweep` 最小只到 600 米，与 near = 0.1 差三个数量级；f 与 n 同量级的极端情形没有实验。
- **没有核实 Persson 的原文。** 只通过 Reed 的转述引用「1/z 在屏幕空间线性」，没有读 Persson 那份笔记本身。
