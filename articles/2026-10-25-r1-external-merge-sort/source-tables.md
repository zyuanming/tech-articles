# OpenDSA 原实验表的许可转录

本页转录 [OpenDSA External Sorting 表 9.6.1](https://opendsa-server.cs.vt.edu/ODSA/Books/CS3/html/ExternalSort.html) 的全部数值，按三种方案拆成窄表，便于阅读。它是**网页可读表格的文字转录与重新排版，不是原文件下载或原截图**。正文使用的24条/10000条记录实验与这里不是同一输入，也不是同一机器，不比较运行秒数。

原表输入为四字节记录（两字节键、两字节数据），每 Megabyte 为256K条记录。文件大小列保留原文“MB/Mb”用法，内存列单位为块；每格是“秒数 / 读写块总数”。原章此处没有充分给出机器配置、操作系统、缓存和重复试验条件，因此不能拿这些秒数预测当前设备表现。K、逗号和星号照原表保留，不自行解释或修正。

阅读这个表最有用的动作是分别观察“时间”和“块数”，并留意初始段与归并方式同时变化。本文的机制解释采用自己可逐项重算的文件实验；没有把原表的性能概括扩大为任何硬件、任何路数都成立的结论。
