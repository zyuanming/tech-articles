# 七桥与欧拉路径：可复算材料

正文：[read.md](read.md)。来源与许可：[sources.md](sources.md)。

这一篇的结论**一支笔一张纸就能验**。代码在这里的作用是另一件事：**验证那条判定规则本身**——把"奇点个数为 0 或 2"这条规则，和"把所有走法一条条试过去"的暴力搜索，放在所有小图上对撞。

## 运行

环境记录见 [run-environment.json](examples/run-environment.json)。**全部代码只用 Python 标准库**（绘图另需 Pillow 与一款中文字体）。

```sh
python examples/run_model.py        # 全部实验，写 results.json
python examples/build_figures.py    # 重绘全部正文图与封面
```

## 实验

### 1. 七桥图与今天的五桥图

1736 年的边：`A-B ×2, A-C ×2, A-D, B-D, C-D`，度数 5、3、3、3。

今天的五桥图：度数为 2、2、3、3。**来源只给出度数，没有给出具体连接**，所以代码里那个具体图是本文按该度数重建的模型，不是城市调查结果。

### 2. 穷举校验（本文对规则本身的验证）

`exhaustive_check()` 枚举所有顶点数 ≤ 4、边数 ≤ 5 的**连通**图，对每一张同时做两件事：

- 用奇偶规则判定；
- 用暴力搜索把所有走法试一遍。

**432 张图，规则与暴力搜索的结果完全一致，零分歧。**

这是这篇最重要的一个实验：它说明"数四个数就能定答案"不是巧合，在这类图上处处成立。

### 3. 一笔画四图形

正方形、信封、房子、三角形加尾巴，各自的度数、奇点个数与判定结果。

### 4. de Bruijn 拼装

k = 4。两个例子：

- `CGTAATGCC`：唯一解，程序拼回原序列。
- `TGTATCTCTTCT`：有两个不同的序列产生完全相同的 k-mer 集合，程序无法区分。

以及 300 条随机序列（种子 3）的歧义分布统计。

## 一个修过的 bug，值得记下来

**de Bruijn 图是有向图。** 边 `CGT → GTA` 只能从 CGT 走向 GTA。

第一版代码把它当成**无向图**，于是"倒着走"也被算作合法路径。倒着走出来的字符串，k-mer 集合其实是对的（一条边无论从哪端走都对应同一个 k-mer），但**重建公式 `首顶点 + 各后续顶点末字母` 只对正向遍历成立**，所以算出了 k-mer 集合对不上的假序列。

修好之后结论**完全反转**：

| | 唯一解 | 平均歧义倍数 |
|---|---|---|
| 当成无向图（错） | 0 / 300 | 2.48 |
| 按有向图（对） | **294 / 300** | **1.04** |

**这类 bug 不会让程序崩溃，只会让结果安静地错掉。** 发现它的办法是给每条重建出来的序列**反查一遍 k-mer 集合**——这也是 `distinct_rebuilds()` 现在只沿边方向走的原因。

## 一个修过的错，值得记下来

第一版正文说"**需要重复的趟数 = 奇点个数 ÷ 2**"。**这是错的。**

它只在"每一对奇点恰好相邻"时成立。反例：三角形 A-B-C 加一条尾巴 C-D-E——奇点只有 C 和 E 两个，但它们相隔 2 条边，必须把 C-D 和 D-E 各重走一遍，所以是 **2** 趟，不是公式说的 1 趟。

更糟的是第一版的代码：

```python
def route_inspection(edges):
    return len(odd_vertices(edges)) // 2      # 把结论当成验证
```

这等于**把要证明的东西写成了代码**，然后说"程序验证过"。它永远返回公式的值，不可能发现公式错了。

现在 `graphs.py` 里有三个函数：

- `route_inspection()`：正确做法——奇点两两配对，BFS 求每对间最短距离，取总距离最小的匹配；
- `route_inspection_naive()`：那条错误的简单公式；
- 两者的对照连同反例都写进 `results.json` 的 `route_inspection_counterexample`。

**本文那两张图恰好都能用单条边配对**，所以简单公式碰巧算对。正文已经写明这一点，并给出了反例。

## 限制

- 没有核对欧拉 1736 年论文原件，正文不引用原文措辞。
- 今天五座桥的具体连接是按来源给出的度数重建的，不是实地调查。
- 没有引用基因组组装方法的原始论文，DNA 例子是自建的玩具例子。
- 正文第 10 节的规则是本文自己写下的。**第一版写成"重复次数 = 奇点个数 ÷ 2"是错的**，只在每对奇点恰好相邻时成立；正确做法是最小权完美匹配。见下。
