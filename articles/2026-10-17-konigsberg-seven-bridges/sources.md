# 来源、图像身份与 AI 辅助说明

核查日期：2026-10-17。正文为面向高中生的原创讲解。文中全部度数、判定结果、路线、计数与统计，均由本文作者实际运行本仓库的代码得到，全部数字都可复算。

## 一手来源及支持范围

1. **题目与城市**：哥尼斯堡（今加里宁格勒）建在普雷格尔河两岸，河中有克奈普霍夫岛与洛姆塞岛两座大岛，与两岸共由七座桥相连；问题是找一条每座桥恰好走一次的路线。出处为 [Seven Bridges of Königsberg 条目](https://en.wikipedia.org/wiki/Seven_Bridges_of_K%C3%B6nigsberg)。
2. **欧拉 1736 年的工作**：欧拉给出数学形式化并证明该路线不存在，这一步奠定了图论的基础，并预示了拓扑学的思想。出处同上条目。**本文没有核对到欧拉 1736 年论文的原件或权威译本**，因此正文不复述论文原文措辞，只描述其方法与结论，并标明这是转述。
3. **抽象那一步**：欧拉指出每块陆地内部的路线选择无关紧要，唯一重要的是"经过的桥的顺序"；因此可以把每块陆地换成一个顶点、每座桥换成一条边，得到图。出处同上条目。
4. **奇偶论证**：除起点与终点外，每次进入一个顶点就要离开一次，所以进入次数等于离开次数；若每座桥恰好走一次，则除起点终点外的陆地，其度数必须为偶数。原问题中四块陆地的度数分别是 5、3、3、3，全部为奇数。出处同上条目。
5. **判定条件与 Hierholzer**：连通且奇点个数为 0 或 2 是**必要且充分**条件；**该条件由欧拉提出，充分性后来由 Carl Hierholzer 证明**。若有奇点，任何欧拉路径必从一个奇点出发、在另一个奇点结束。出处同上条目。正文据此把"必要性"与"充分性"分开归属，没有把整个定理归给欧拉一人。
6. **今天的状态**：七座桥中两座毁于二战对哥尼斯堡的轰炸，另两座后来被拆除并改建为公路；三座留存，其中只有两座是欧拉时代的原桥（一座 1935 年重建）。同一位置现存五座桥，四个顶点的度数变为 2、2、3、3，因此**现在存在欧拉路径**，但必须从一座岛出发、在另一座岛结束。出处同上条目。
7. **中国邮递员问题**：寻找覆盖每条边至少一次的最短闭合路线；当图存在欧拉回路时该回路即最优；否则要重复最少的边。**该问题能在多项式时间内求解，与 NP 难的旅行商问题不同**；它最早由中国数学家研究。出处为 [Route inspection problem 条目](https://en.wikipedia.org/wiki/Route_inspection_problem)。**正文第 10 节的规则是本文自己写下的，不是引用来源中的现成公式。**

关于这条规则，本文写作过程中出过一次错，值得记下来：**第一版正文写的是"重复次数 = 奇点个数 ÷ 2"。这个公式是错的。** 它只在"每一对奇点恰好相邻"时才成立。反例：三角形 A-B-C 加一条尾巴 C-D-E，奇点只有 C 和 E 两个，但它们相隔 2 条边，要一次走完所有边必须把 C-D 和 D-E 各重走一遍，所以是 2 趟而不是 1 趟。

第一版的代码 `route_inspection()` 直接把这条公式写成了 `len(odd_vertices(edges)) // 2`，等于**把结论当成验证**，并没有检验它。现在代码里有三个函数：

- `route_inspection()`：正确做法——把奇点两两配对，用 BFS 求每对之间的最短距离，取总距离最小的匹配；
- `route_inspection_naive()`：那条错误的简单公式；
- `route_inspection_counterexample`：上面那个反例，两个函数在这里给出 1 与 2 两个不同的答案。

本文正文里的两张图（哥尼斯堡七桥、今天的五桥）**恰好**都能用单条边配对，所以简单公式碰巧算对——但正文已明确写出它并不普遍成立。
8. **de Bruijn 图与基因组组装**：把测序得到的短片段（k-mer）建成 de Bruijn 图、再用欧拉路径重建序列，是基因组组装的经典方法。**本文没有引用该方法的原始论文**，正文只把它当作一个应用场景来演示，并明确说明本文用的是自建的玩具例子，不是任何真实组装流程。

## 本文实际运行的实验

`examples/run_model.py` 只用 Python 标准库。环境记录见 `examples/run-environment.json`。

- **1736 年七桥图**：边 `A-B ×2, A-C ×2, A-D, B-D, C-D`，度数 5、3、3、3。
- **今天的五桥图**：度数为 2、2、3、3 的一个重建。**来源只给出度数，没有给出具体连接**，因此正文与 README 都标明这是本文按该度数重建的模型，不是实测的城市调查。
- **暴力搜索**：枚举所有可能的走法，确认七桥图不存在欧拉路径。
- **穷举校验**：把"奇点个数为 0 或 2"这条规则，与暴力搜索放在**所有**顶点数不超过 4、边数不超过 5 的连通图上对撞。共检查 432 张图，规则与暴力搜索**结果完全一致，零分歧**。这是本文对规则本身的独立验证。
- **一笔画四图形**：正方形、信封、房子、三角形加尾巴。
- **de Bruijn 拼装**：k = 4，两个例子（唯一解与有歧义各一），以及 300 条随机序列的歧义分布统计。

### 写作过程中实际踩到并修好的一个 bug

de Bruijn 图是**有向图**：一条边 `CGT → GTA` 只能从 CGT 走向 GTA。

本文第一版代码把它当成**无向图**处理，于是"倒着走"也被算作合法路径。倒着走出来的字符串，其 k-mer 集合其实是对的（因为一条边无论从哪端走都对应同一个 k-mer），但**重建公式只对正向遍历成立**，所以算出了一个 k-mer 集合对不上的假序列。

修好之后的结论**完全反转**：修正前统计出"300 条随机序列没有一条有唯一解，平均歧义 2.48 倍"；修正后是"294 条有唯一解，平均歧义 1.04 倍"。正文给出的全部是修正后的数字。

**这个 bug 值得单独记一笔**：它不是算术错误，而是"把有向的东西当成无向的"。它不会让程序崩溃，只会让结果安静地错掉。README 里也记了这一条。
