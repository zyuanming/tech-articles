# 来源与说明

## 图片

11 张正文图与 `cover.png` 全部是本文原创的教学示意，由 `examples/build_figures.py` 生成。几何断言写在 `examples/figkit.py` 里：文字不出画布、不互相压、任何字号的文字换算到 354 px 宽的显示宽度后不小于 12 px。没有使用照片、截图或第三方素材，因此不涉及第三方署名与许可。

图里的曲线、柱子、色块全部来自 `examples/results.json`；`build_figures.py` 只负责取值和摆放，不改数。几点具体说明：

- 图 01 上半部分是表格（三行：x = −1、0、1 的函数值，加上 x = 0.5 的真值与插值），下半部分才是曲线；曲线用的是 `quad` 那 201 个点。
- 图 02 与图 03 用的是同一套画法：纵轴从数据的最小值到最大值各留一点边，横轴固定 −1 到 1，所以两张图可以直接对比；差别只在纵轴的落点上（图 02 要装下 1.96 的振荡，图 03 只需要装下 1）。
- 图 04 的纵轴是对数刻度，等距那条线的相邻两点来回跳（n = 29 到 1130、n = 30 到 334），画出来是锯齿；脚本把小于 10⁻¹⁶ 的值夹到 10⁻¹⁶ 只是为了不取 log(0)，正文里没有用到这么小的误差。
- 图 08 是一张 121 × 23 的热图（横轴 x 的 121 个采样点，纵轴 n 从 3 到 25），直接画 `heat` 里的 |f − p|，按六档分色。
- 图 11 是三行结论文字，没有数据。

## 数字

正文和图片里的每个数字都由 `examples/interp.py` 算出、`examples/run_model.py` 写进 `examples/results.json`，`examples/build_figures.py` 只从 `results.json` 取值。跑一遍：

```sh
cd examples && python3 run_model.py && python3 build_figures.py
```

纯标准库（画图需要 Pillow），`run_model.py` 约 0.9 秒，`build_figures.py` 约 3.2 秒。

模型设定：

- **`meta`**：f(x) = 1/(1 + 25x²)，a = 25，区间 [−1, 1]，全程 float64（Python 的 float）。不需要更高精度——这里要看的正是双精度够不够，而双精度到 n = 30 为止没有参与误差。
- **`hand`**：三个等距节点 −1、0、1。用单项式基做最小二乘（也就是解 Vander­monde 方程，三点时是精确的），给出系数 [1, 0, −25/26]、x = 0.5 处的真值、插值、差，以及抛物线在 x = 1 处的值（用来核对系数）。
- **`quad`**：同一条抛物线在 201 个均匀点上的 f 与 p，给图 01 画曲线。
- **`curve`**：n = 11，两种节点各 401 个均匀采样点，逐点记 f、p；`sup` 是这 401 点上的最大 |f − p|（正文的 1.916 与 0.1092）。
- **`sweep`**：n 从 2 到 30，两种节点各算 `sup_error`（2001 点）与 `lebesgue`（2001 点），记录取到最大值的位置。正文的表和图 04、图 05 全部取自这里。
- **`nodes`**：n = 11 两种节点的位置、相邻间距、最小间距。切比雪夫的最小间距 0.080189，最大 0.281733。
- **`basis`**：n = 11，逐个节点在 2001 个点上扫每个基函数的绝对值，取每个 i 的峰值。等距的最大值 6.5069 出现在第 4 个节点（0 起算），切比雪夫的最大值 1.2711 出现在最后一个。
- **`heat`**：n 从 3 到 25，每个 n 在 121 个点上算误差，存成矩阵。图 08 直接画它。
- **`rates`**：a = 1 / 5 / 25，n 从 4 到 30，切比雪夫节点，2001 点上的最大误差。`rho_theory` 是极点对应的椭圆参数，`rho_fit` 是对 log 误差与 n 做最小二乘后取 exp(−斜率)。拟合会丢掉误差 ≤ 10⁻¹⁶ 的行（那已经是双精度的底）。
- **`absx`**：n 从 4 到 30，切比雪夫节点插 |x|；`ratio` 是同样的最小二乘拟合给出的「每加一点乘几」。
- **自检**：六条——原来的中点值正好是 1、二次项系数等于 −25/26、切比雪夫在 n = 11 时优于等距、n = 30 时仍然优于、等距的 Lebesgue 常数随 n 单调递增、`ellipse_rho(0.2)` 等于 1.21978。

关键数字的来历：

- **1.92 与 0.109**：11 个节点、401 个采样点上的最大偏差；扫表用 2001 点是同一批量在更密网格上的值（1.916 与 0.1092）。
- **334**：n = 30 的等距插值在 2001 点上的最大偏差，出现在 x = −0.98 附近。函数的最大值是 1，所以这是「偏差是函数本身的三百倍」。
- **1130**：n = 29 的最大偏差，比 n = 30 还大三倍多。相邻 n 的奇偶交替在图上就是锯齿，正文只用来说明「包络在涨」。
- **λ = 29.9 / 283 / 1.10×10⁴ / 3.45×10⁶**：等距在 n = 11 / 15 / 21 / 30 上的 Lebesgue 常数。在 2001 点、10001 点、40001 点三种网格上量到的值逐位相同（n = 30 都是 3.448e6），所以这不是被采样网格截出来的数。它与渐近式 2^(n+1)/(n ln n) 相比小约三倍：那个式子要到很大的 n 才准。
- **λ = 2.49 / 3.13**：切比雪夫的 Lebesgue 常数，与 (2/π)ln(n+1) + 0.9625 的下界对得上（n = 30 给 3.1278）。
- **6.51 / 1.27**：等距与切比雪夫基函数振幅的最大值（n = 11）。
- **ρ = 2.4142 / 1.5427 / 1.2198**：极点 ±i、±i/√5、±i/5 对应的椭圆参数，公式是 ρ = |z + √(z²−1)|，极点在虚轴上时就是 y + √(1+y²)。拟合值 2.4142 / 1.5413 / 1.2180。
- **0.82、0.41、0.93**：ρ 的倒数，也就是「每加一个节点误差乘几」。a = 25 是 0.8197，a = 1 是 0.4142，|x| 的拟合值是 0.9317（端点比值开 26 次方是 0.9227，差在锯齿）。
- **43 与 73**：从 n = 30 的 0.005156 出发，按 0.82 衰减到 10⁻⁶ 需要 k = ln(5156)/ln(1/0.82) = 43.1 个节点，合计 73 个。
- **0.080189 / 0.281733 与 3.51**：n = 11 切比雪夫节点的最小、最大间距，以及它们之比。

## 文献

- Runge, C., *Über empirische Funktionen und die Interpolation zwischen äquidistanten Ordinaten*, Zeitschrift für Mathematik und Physik 46 (1901), 224–243。这篇没有 DOI；卷期页码按二次文献核对，原文扫描在 archive.org 的卷合订本 `zeitschriftfrma12runggoog` 里。正文只用了「1901 年、这个标题、这个例子」三件事，没有转述原文措辞。
- Faber, G., *Über polynomische Entwickelungen*, Mathematische Annalen 57 (1903), 389–408，DOI `10.1007/bf01444293`。不可能定理：任何节点序列都存在一个连续函数使插值不收敛。
- Bernstein, S., *Sur la meilleure approximation de |x| par des polynômes de degrés donnés*, Acta Mathematica 37 (1914), 1–57，DOI `10.1007/bf02401828`。|x| 的最佳逼近误差按 1/n 掉。
- Trefethen, L. N., *Approximation Theory and Approximation Practice*, SIAM, 2013（扩充版 2019，DOI `10.1137/1.9781611975949`）。Runge 现象、Lebesgue 常数、伯恩斯坦椭圆与 ρ⁻ⁿ 收敛率的标准讲法。正文里的框架（误差 = E_n × (1 + λ_n)、节点决定 λ、极点决定 ρ）按这本书的叙述组织，但没有引用它的具体页码，也没有照抄它的例子。
- Lebesgue 常数的两个渐近式（等距的 2^(n+1)/(n ln n)、切比雪夫的 (2/π)ln(n+1) + 0.9625 夹逼）复核过公开的百科条目，与实测值一致。

## 明确没有做的事

- **没有用任意精度重算。** 双精度是讨论对象本身；如果换成 50 位小数，n = 30 的等距误差会变（消去误差小一些），但「等距比切比雪夫差三个数量级」这个结论不会变。正文没有给「双精度开始失真」的界限。
- **没有比较其他重建方式。** 最小二乘、样条、有理逼近（比如 Padé）都能绕开 Runge 现象，正文没有做对比实验，只在讲切比雪夫节点时提了一句「它把节点按难度重新分配」。
- **没有做二维/三角网格。** 谱元里的 Gauss–Lobatto 节点是同一套想法的推广，但本文只有一维区间上的实验。
- **没有测实际库的行为。** 没有跑 numpy 的 `Chebyshev.fit`、没有比较不同实现的数值稳定性。中途还试过一节「单项式基的 Vander­monde 条件数」：n 加到 52 时条件数 4.6×10¹⁸，但用单项式基求出系数再求值，误差 2.2×10⁻¹⁵，和重心插值的 1.3×10⁻¹⁵ 同一量级，没有出现「条件数爆炸导致结果崩掉」的现象，整节删掉了。`interp.py` 里只留下给手算例子用的 `monomial_fit` / `solve`。
- **没有把「最佳逼近」与「切比雪夫插值」分开量。** |x| 那一节说的是插值误差（0.0334），不是 Bernstein 论文里的最佳逼近误差——插值比最佳逼近差几倍，正文只用来说明「掉得慢」。
- **没有做到 n > 30。** 等距在 n = 29 已经到 1130，再往上双精度的消去误差会开始污染「最大误差」这个量，而 λ 又会涨到 10⁷ 以上，两者混在一起说不清。
- **没有做时间测量。** 全文没有计时，也没有内存占用。
