# 复现本文字节模型

原创代码、JSON结果与本说明采用 CC0-1.0；生成的原创PNG采用 CC BY 4.0。第三方Python/Pillow/Playwright/字体各遵循自己的许可证，本目录不包含它们的分发副本。

默认编码保留满块后的最后空码字；`compact=True` 只在最后完整FF块后省去无用01。编码函数不加帧定界符，解码函数不拆帧。`Receiver` 才负责用00分段：忽略裸零造成的空片段，初始未知边界时可丢到第一个零，超限后也丢到零再恢复。

在本目录运行：

```sh
python run_examples.py
python build_figures.py
python demo_web.py
```

模型只需Python标准库。绘图需要Pillow和fontTools，以及Noto Sans CJK中文字体；找不到合适字体会报错，不静默退回缺字字体。教学界面服务地址会在命令行显示，默认是本机端口8018。界面不连接任何设备；点击“送入下一片段”调用真实Python接收器，所有片段由该实验固定指定。

重新截取实际网页并检查桌面/手机：

```sh
python capture_demo.py \
  --evidence-dir \
  ../../../../cobs-audit
```

这一步需要已安装Playwright与Chromium。证据目录位于文章之外，请按本地位置调整；不要把浏览器检查日志加入文章。截图先写到证据目录，再复制本篇要求公开的教学截图至assets；`figure-metadata.json`同步更新。先运行绘图，再运行截图程序，元数据才包含全部十八张图。程序输出的检查记录不是独立审读结论。

`results.json`包含完整主例编码事件、解码事件、两种策略的边界码字、五次接收状态与错误案例。字节数组里的数是JSON十进制整数；展示时转为两位十六进制。图片中的字节角色来自编码事件或实际解码位置，不能仅凭字节数值判定。

随机检查的消费顺序为：种子2026102518，重复1200次，每次先生成长度0..2199，再生成该数量的0..255字节。穷举字母表为0、1、255，长度0..7。另检查所有0..1024长度的全零和全55输入；主例十字节帧全部512种分段均跑完。

默认不记录轨迹时，核心编解码是线性扫描；`record=True`会重复复制前缀，只为教学图提供逐步证据。整个演示还存储接收历史，当前帧限长不是整个进程内存上界。有限测试不代替生产协议审计或真实设备测量。
