# 复算 Sagnac 教学模型

先读[正文](../read.md)中的参考系、方向和适用条件。代码只计算所列模型，不控制仪器，也不提供设备标定。

## 执行

在本目录使用 Python 3 运行：

```sh
python run_examples.py
python build_figures.py
```

第一条只依赖标准库，重写 `results.json`；第二条需要 Pillow、fontTools，以及 Noto Sans CJK 字体，读取该 JSON，重写本篇 PNG 和 `figure-metadata.json`。缺字或缺字体直接报错，不悄悄换成方框。绘图代码不下载任何第三方图片。

`run_examples.py` 开头的 c、R、omega、wavelength、turns 是主算例输入，单位依次为 m/s、m、rad/s、m、匝。可修改后依次重跑，但正文是固定参数的讲解，程序不会自动改写正文。另有独立的可见运动演示、绕向反例、矩形反例、地球转动模型与零偏积分输入，不能把它们混成同一次实验。

## 预期数值

|量|当前输出|
|---|---|
|静止单圈时间|约2.095845 ns|
|单匝旋转时间差|约1.3981973×10⁻¹⁸ s|
|单匝相位差|约0.001699172 rad|
|1000匝相位差|约1.699172 rad|
|1000匝方向时间差|约1.3981973 fs|
|n=1.5的1000匝传播时间估计|约3.143768 μs|
|固有时间相对坐标时间的差别|约5.56325×10⁻²⁰|
|另一组地球转动模型拍频|约293.3422 Hz|

普通双精度把两个约纳秒的时间相减，得到约10⁻¹⁸ s差值时会损失约9位有效数字，主信号仍可保留数位；但无法可靠分辨本例约10⁻²⁰的相对固有时修正。为核查这种更小的相对项，程序使用70位十进制，对 n=1、1.5、2 逐项计算速度合成和交会；比较差值与代数表达式，容差为10⁻⁶⁵ s。这里的高精度保证模型运算可追踪，输入的十进制圆周长仍来自双精度 π，不表示物理长度有70位准确度。

程序还检查相位两种写法一致、余弦正负对称、60°投影减半、反向匝数抵消，以及同周长异面积。曲线使用301个相位采样；恒定零偏按0到60秒计算。`visible` 是另设 v/c=0.2 的放大运动模型，不能用于解释真实教学线圈移动了四分之一圈。

图形中的尺寸比较共用尺度；角度、轨迹交点、条形比例和波形相位都读实际 JSON。画布的1062 px宽、40 px最小字号及屏幕边距属于版式参数，不是物理输入。
