# 复算压电喷墨的三个教学近似

需要Python 3.12；绘图另需Pillow、fontTools和Noto Sans CJK字体。数值计算只用标准库，无随机过程。建议把本目录及相邻assets、originals一起复制到工作副本后运行，程序会覆盖副本里的results.json和原创PNG；原始照片不会重编码。

在examples目录执行：

```sh
PYTHONDONTWRITEBYTECODE=1 \
  python run_examples.py
PYTHONDONTWRITEBYTECODE=1 \
  python build_figures.py
```

`run_examples.py`做三种相互独立的近似，参数集中在文件开头的P字典。它们用于同一教学对象的不同观察尺度，不是顺序连接的设备预测程序：

1. 用自由容积变化与有效顺应性估算封闭、均匀压力极限。
2. 用人为设定的三角脉冲、20µs延迟与−0.8反射幅度系数展示线性叠加。未求解声学偏微分方程。
3. 直接指定20kPa、20µs的喷嘴上游压力，用常数4kPa毛细项、泊肃叶阻力和液柱惯性求解析流量；另用20000小区间的梯形积分核验体积。没有求自由表面，不能预测断裂或卫星滴。

正文数值来自results.json，包括体积21.276366pL、末端平均速度2.119125m/s和条件等效球径34.379504µm。黏度比较只改黏度，其余输入不变。球冠算例复核两接触角保持同一体积，绘图用相同的长度尺度。Re、We、Oh统一用喷嘴直径与局部模型末端速度；检查Oh=√We/Re。

`build_figures.py`读取results.json，生成12幅全新原创图和figure-metadata.json；另外登记保留原字节的项目照片。检查文字出界、声明框归属、文字相互重叠、最小40px字号、对比度、字体字形、墨迹像素、图像尺寸和比例条排序。构图中的位置是版式常量，图上的物理数值与数据曲线、比较条长度由JSON计算。原始项目图不适用原创图40px规则，正文已提供中文解释。

检查只能发现特定几何问题，不能证明模型对应真实喷头，也不能代替读图。公式中的自由表面、入口动态、非牛顿流动、气泡和喷嘴阵列均未求解。
