# 可选的纯软件模型

本目录不操作硬件，不采集传感器，不连接网络。温度和距离均是人为测试输入；示例验证双门槛状态规则，不是芯片测量。读正文无需运行。

## 1. 核心数值

在本目录运行：

```bash
python schmitt_lab.py
```

只用Python标准库，实际作者运行环境为Python 3.12.14。重写本目录 `results.json` 与 `trace.csv`，不会改正文。

- 单门槛：`input >= 28`。
- 双门槛：`input >= 28`开，`input <= 26`关，中间保持，初始关。
- 9次读数：25、27、28.2、27.8、28.1、27.9、27、26.1、25.9；状态切换分别4次、2次。
- 12秒输入在0—4秒为25+0.8t；4—8秒为28+0.18sin(2π·3(t−4))；8—12秒为28−0.6(t−8)。在0至12秒含端点按0.02秒采样，601行。状态切换分别26次、2次。
- 558项离散边界与状态组合；5000项固定种子20261013的带内双初态验证；4种非法数值/门槛用例。
- 理想比较器参考节点：2.5V通过10kΩ、输出通过40kΩ。输出0/5V时分别得2/3V。输入不吸电流、理想固定输出电压、共用电位参考，未模拟器件内部晶体管和传播延迟。

真实输入缺失、NaN、无限大应有系统层故障策略；本教学函数只抛异常，不指定安全控制动作。

## 2. 生成原创显示帧

需要Pillow及Noto Sans CJK字体。作者环境中字体路径为 `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`，其他系统可修改 `render_outputs.py` 的FONT常量以指向本机可用中文字体。

```bash
PYTHONDONTWRITEBYTECODE=1 python render_outputs.py
```

生成 `rendered/` 下8幅624×210显示帧，取九次读数中的第3—6次。它们是由真实执行规则驱动的原创教学显示，不是现成软件界面或硬件照片。正文图01将同一 `panel` 函数的帧缩排，并把关键开/关与温度另用大字标出。

正文图29是同一状态规则应用于距离的输出：对输入取负号，low=-7、high=-5，初始False；距离8、4.9、5.1、4.8、6、7.1得到0、1、1、1、1、0。

## 3. 其他图的数值口径

- 图08、26是输入对输出的理想回线，横轴不是时间。
- 图10、11、18是离散样本，横轴从0计；状态线按样本保持绘制，不主张采样间发生了某条实测模拟波形。
- 图27：输入在t=0.05秒从0切到3.3V；响应为t<0.05时0，否则3.3×(1−exp(−(t−0.05)/0.05))。时间常数0.05秒，301点，步长0.001秒。经过一个时间常数时完成1−exp(−1)≈63.212%的变化。
- 图20数值来自TI SN74HC14 Rev L §5.5，4.5V供电、25℃条件；没有把范围当作本地实测。
