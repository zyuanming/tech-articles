# 可靠方向判断：同一浮点输入的两种计算

正文：[read.md](read.md)。这些数据全部为本文构造，实验只在本地运行。没有调用CGAL、编译Shewchuk程序或运行游戏引擎，也没有把结果当成工业几何性能测试。

## 程序与条件

```sh
python3 examples/run_orientation.py --output orient-run-01
```

输出目录须尚不存在。代码仅使用Python标准库，不联网、不安装依赖，生成results.json、grid.csv、stdout.txt。已保存的对应结果为[expected-results.json](examples/expected-results.json)、[grid.csv](examples/grid.csv)、[原始标准输出](originals/experiment-stdout.txt)。

坐标为无量纲二维Cartesian坐标，x向右、y向上。普通公式固定以第一个参数为原点：D=(Bx−Ax)(Cy−Ay)−(By−Ay)(Cx−Ax)。精确参考将每个实际float用Fraction.from_float转换为其完全相同的有理数值，再求该多项式。

教学过滤器不是Shewchuk算法的移植。它给每个输入初始区间[x,x]，区间相减和相乘每次用math.nextafter向外扩一个相邻浮点数。若下界>0或上界<0，直接确认；否则调用精确分数。任何非有限中间端点或溢出使区间层放弃，进入分数层。输入NaN或正负无穷直接拒绝。

包含保证依赖基本加减乘正确舍入、binary64浮点及正常工作的nextafter/渐进下溢条件，不是对任意编译器fast-math、任意处理器设置或任意数类型的保证。本次环境为Python 3.12.14，radix=2、mant_dig=53；运行记录见[run-environment.json](examples/run-environment.json)。验证代码对每个获得有限区间的检查，另用精确分数确认真实值位于该区间内。测试不能替代算术假设；实际工程优先使用经过平台验证的成熟谓词实现。

该过滤器保守，重复扩张会造成较宽区间；回退不等于普通结果一定错误。精确层把已存浮点坐标当作输入，不恢复转换前的十进制、整数或真实测量值。

## 固定例子和实际检查

主例N=2^27，A=(0,0)、B=(N,N−1)、C=(N+1,N)。精确D=1，普通公式D=0；循环换起点的普通结果为0、1、1。输入整数全部可精确表示。区间约[−14,20]，完整端点保留在JSON，严格比较使用精确分数而非显示后近似值。

凸包使用同一份单调链程序，仅替换方向谓词：普通保留A、C两个点，过滤/精确版本保留A、B、C三个点。图7用X=x/N、Y=Ny−(N−1)x展示，矩阵行列式为1，所以保持有向面积，形状和比例改变。绘图从实际输出顶点列表读取，不作原坐标等比例视图主张。

缩放例：A=(0,0)、B=(1,0)、C=(1,2^-40)。固定epsilon=10^-9会把它判成0；所有坐标乘2^20以后D=1，又被判为正。可靠谓词对两者均为正。

近邻网格：保持主例A、B固定，C每个坐标统一移动i×2^-25、j×2^-25，i、j为−15至15，共961点。这是固定步长网格，所有点可精确表示。特别地，y在2^27以下时，局部相邻浮点间隔是2^-26，因此这里每格跨两档，不能称为整个网格每一格都严格相邻的浮点数。31点普通误判、283点精确回退；可靠结果全部等于分数参考。

普通样本：random.Random(240014)，500组，每组6个坐标均由uniform(−100,100)得到。本次500组全部由区间层确定。不是均匀覆盖浮点全集，也不是概率性正确率证明。

另外检查全部6种顶点排列、共线、重合、乘积极小和溢出量级，共1475次方向及有限区间包含检查；其中存在重复的主例，不能当成1475种独立特殊输入。3种非有限输入另作拒绝测试。

输入舍入示例：M=2^53，原始整数B=(M,M)、C=(M+1,M)，转成float后两点相同；分数层正确返回已存数据的D=0，而原始整数行列式为−M。
