# 两阶段提交教学模型

```sh
python two_phase_lab.py
```

仅用标准库，在CPython3.12.14实际运行；不连接数据库、不执行任何外部操作。程序打印安全性枚举数量、三种故意错误版本的反例，以及正常路径。持久状态原子、单笔事务、固定参与者、消息不冒名不损坏；仅安全性，不保证故障时进展。模型与数量的精确范围见sources.md。
