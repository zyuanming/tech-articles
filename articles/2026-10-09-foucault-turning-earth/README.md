# 地球正在转，为什么博物馆里的一颗摆球能把它“抓现行”？

正文：[read.md](read.md)。本文把“球走了一趟”和“这一趟走的方向变了”分开，先在北极做思想实验，再用 |sin φ| 把结果搬到巴黎与悉尼，最后说明博物馆为什么能给摆球补能量、以及补能量为什么不一定毁掉测量。所有速率都是理想公式的结果，不是实体装置的实测。

## 环境与运行

本次 Python 3.15.2，只用 `math` 与 `json`。脚本不联网、不下载、不安装。

在本文目录执行，输出目录须为空或不存在：

```sh
python3 examples/latitude_rates.py --out ./my-results
```

输出 `results.json`，与本次 [expected-results.json](examples/expected-results.json) 核对。

## 数值口径

- 恒星日 86164.0905 秒，地球自转合每小时 15.0411°；理想小振幅傅科摆的进动速率取 `自转速率×|sin φ|`。
- 北纬 30°：7.52°/时，一圈 47 小时 52 分。巴黎 49°：11.35°/时，一圈 31.7 小时（31 小时 43 分）。悉尼 34°：8.41°/时。赤道：0°/时。北极：15.04°/时，一圈 23 小时 56 分。
- 67 米长摆的小振幅周期 `2π√(L/g)` 约 16.42 秒，与“一次往返十几秒”相符；28 千克摆球不进入周期公式。
- 公式不含有限摆幅、椭圆轨道、支点柔度与空气阻力修正；真实装置的进动会偏离这个理想值。
- 本文没有做实体摆实验，也没有声称完成过。
