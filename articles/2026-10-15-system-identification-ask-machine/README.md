## 时间、单位、模型

采样周期1秒。u[k]在区间[k,k+1)保持，y[k]是时刻k的温差读数，y以°C为单位，u为无量纲归一化功率。每行回归用(y[k],u[k])解释y[k+1]。y[0]=0，未拟合截距，环境基准已视作已知且固定。

生成关系y[k+1]=0.8y[k]+0.4u[k]+w[k]，w按模型设定为独立零均值高斯扰动，标准差0.03°C，使用Python random.Random.gauss生成伪随机样本。不是单独叠在传感器输出上的测量误差；没把两类噪声混用。温差允许微小负值，图10的纵轴包含负温差。估计程序不使用保存的w列；那一列仅用于生成证据复核。

训练输入：random.Random(2700)产生24个0/1值，各保持5秒，120个转移、121个输出。训练扰动种子2701。

验证输入：八秒0、八秒1、八秒0.5、八秒0、八秒1，整段重复两次，80个转移、81个输出。验证扰动种子2702。所有参数只用训练记录估计，验证集不参与拟合。本例未反复依验证结果调模型或超参数；一般反复调参后还应另留最终测试数据。

## 最小二乘如何算出两个数

令X_k=y[k]、U_k=u[k]、Z_k=y[k+1]。把每行残差Z_k−aX_k−bU_k平方求和，分别对a和b求导并令其为0，可得两条正规方程：

```text
sum(X*X) * a + sum(X*U) * b = sum(X*Z)
sum(X*U) * a + sum(U*U) * b = sum(U*Z)
```

代码以math.fsum累加这五个数，用2×2行列式显式求解。行列式接近零时拒绝给唯一参数，不假装已经辨识成功。教学实现的阈值是1e-12×max(1,sum(X²)sum(U²))，只服务本例量纲和范围，不是通用数值线性代数算法。生产场景可使用QR/SVD及合适的缩放，而非直接正规方程。

训练得到a=0.80824378789997，b=0.39564451871440987。静态基线Z=cU也只用训练集求c=sum(UZ)/sum(U²)=1.2681638104694464。

训练一步RMSE=0.030356775°C。验证一步RMSE=0.029417234°C；自由运行RMSE=0.040772971°C；静态基线RMSE=0.523967745°C。计算均排除初始点y[0]，只比较相同80个下一时刻输出。自由运行不用未来实际y、不给未来w，初值使用已知y[0]；一步预测每一步使用实际y[k]。

稳态例是独立无扰动的人工记录u=1、y=2，20条转移正规方程行列式为0。三候选(a,b)=(0.5,1)、(0.8,0.4)、(0.9,0.2)都符合，图1展示它们从y0=2、u=0开始的实际冷却计算。另一个从0开始的无扰动阶跃可完整恢复两参数，防止把“只看稳态”错误推广为“阶跃输入永不含辨识信息”。

残差自相关采用样本均值去中心后的定义：分子为sum(d[k]d[k-lag])，分母为sum(d[k]²)，分子索引仅保留有效配对。这里不作无偏修正、不画显著性置信带。一步滞后样本值为动态0.009944642、静态0.793369675。图14为lag1至8；不称为正式通过白噪声检验，没有实际计算输入残差互相关。

100次重复采用同一训练输入，扰动种子27100至27199。a样本均值0.799952845、样本标准差0.004649402；b均值0.399749332、标准差0.005772504°C。样本标准差分母为99。只是本次已知生成规律的重复结果，不是真实设备置信区间。图13每点对应一份保存结果，不人为补散点。

范围外例另外比较两个无扰动模型：一个始终使用0.4u，另一个使用0.4×clip(u,0,1)。在训练0≤u≤1范围内两模型完全相同，输入2时分开；都用生成系数0.8/0.4，不是把额外拟合误差混进外推反例。

## 可复查检查与图像

程序验证：无扰动两参数恢复误差<1e-12；稳态退化检测；三候选满足同一稳态；训练残差与两个回归列的内积<1e-11；估计点附近25组参数的平方损失不低于最优点（浮点容差1e-12）。这些检查不是证明任意真实系统已正确辨识。
