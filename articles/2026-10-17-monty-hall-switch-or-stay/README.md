# 蒙提霍尔问题：可复算材料

正文：[read.md](read.md)。来源与许可：[sources.md](sources.md)。

这道题的答案不靠"相信"，靠三种互相独立的方法算出来：**精确枚举**、**精确分数**、**蒙特卡洛模拟**。三者必须一致。

## 运行

环境记录见 [run-environment.json](examples/run-environment.json)。**全部代码只用 Python 标准库**，不需要安装任何东西（绘图另需 Pillow 与一款中文字体）。

在本篇目录中执行：

```sh
python examples/run_model.py        # 全部实验，写 results.json
python examples/build_figures.py    # 重绘全部正文图与封面
```

首次运行时的原始标准输出保存在 `originals/model-stdout.txt`。

## 三套算法

### 1. 精确枚举

把"车在哪（3 种）× 你选哪扇（3 种）"共 9 种情形全部列出，逐种判断。这是最笨也最不会错的办法，正文第 3 节的表格就是它的输出。

### 2. 精确分数

用 Python 的 `Fraction` 做有理数运算，全程不碰浮点。用于：

- 一般公式 `1/n` 与 `(n−1) ÷ [n × (n−1−k)]`；
- 条件概率（按主持人实际开了哪扇门分别计算）。

### 3. 蒙特卡洛模拟

固定随机种子跑 200,000 次，覆盖四组配置：3 门知情、3 门**不知情**、10 门、100 门。

## 一个写作过程中实际踩过的坑

第 10 节要算"在他开了 3 号门的条件下，换的胜率是多少"。如果把 (车, 选择, 开的门) 三元组当成**等可能**的，会算出"随机主持人开每扇门都是 1/2"，与总体的 2/3 自相矛盾。

错在哪里：**这些三元组并不等权。**

- 当玩家已经选中车时，主持人有**两只**羊可选，每个选择各占一半权重；
- 当玩家没选中车时，主持人**只有一个**选择，权重是 1。

按真实权重重新枚举后，结果与模拟一致。代码里 `conditional_by_opened_door()` 的注释写明了这一点。**这正是"看起来对称不等于真的对称"的一个具体例子**——也是本文想让读者记住的那句话。

## 四组实验

1. **九种情形枚举**：3 胜 6 胜。
2. **一般公式**：3 / 4 / 10 / 100 扇门四组取值。
3. **模拟**：四组配置各 200,000 次；其中"不知情"那组要丢弃主持人开到车的 66,773 次，正文与图中都标明了有效次数。
4. **条件概率**：两种主持人策略下，按他实际开的门分别计算。

另外记录了一条**收敛曲线**：同一套程序在 10 / 100 / 1,000 / 10,000 / 100,000 / 200,000 次时的累计胜率，用来说明"跑十次结果和理论不符"是次数不够，不是理论错了。
