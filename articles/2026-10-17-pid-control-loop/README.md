## 运行

环境记录见 [run-environment.json](examples/run-environment.json)。**全部代码只用 Python 标准库**，不需要安装任何东西（绘图另需 Pillow 与一款中文字体）。

在本篇目录中执行：

```sh

python examples/build_figures.py    # 重绘全部正文图与封面
```

首次运行时的原始标准输出保存在 `originals/model-stdout.txt`。

## 被控对象

`control.py` 里的 `Thermal` 是一个**两级滞后**模型：

```
dT1/dt = (K·u − (T1 − T_room)) / τ1
dT2/dt = (T1 − T2) / τ2
```

`K = 200`、`τ1 = 60 s`、`τ2 = 20 s`、`T_room = 20 °C`、`u ∈ [0, 1]`。

选两级而不是一级，是因为**一级滞后永远不会震荡**——用一级对象做实验，"超调""极限增益"这些概念根本不会出现，整篇文章的核心现象也就无从谈起。第一版程序确实踩过这个坑：在单滞后对象上搜索"极限增益"，搜出一个 `Ku = 37.2` 的假值（第 17 节正文写明了这一点）。

## 三个关键机制

### 1. 稳态误差公式与模拟互相印证

正文第 5 节给出 `e = (SP − 20) / (1 + 200·Kp)`。这张图里的第三列是纯代数，第二列是模拟跑出来的，**五行吻合到小数点后四位**（最大偏差 3.9e-7，量级来自 `results.json` 保存的六位小数舍入）。两条独立路径指向同一个结论，才写进正文。

> 写作过程中这里出过一次错：初稿的公式写成 `e = 0.3 ÷ Kp`（把"稳态功率"直接当成"控制器的输出上限"来推），算出 150 °C，而模拟给的是 42.9 °C。用 `Thermal` 的稳态条件重推之后才发现漏掉了"炉子的输出也要自洽"这一步。图与正文现在给的都是改正后的推导。

### 2. 极限增益是搜出来的，不是查出来的

`ultimate_gain()` 用二分法从 0.002 到 4 搜索使回路等幅振荡的 `Kp`，判据是振荡幅度是否还在衰减。当连最大试探值都收敛时，它**返回 `ku = None` 并附上一句说明**，而不是硬凑一个数。正文第 17 节正是靠这个诚实的返回值发现"两级滞后系统没有极限增益"。

### 3. 倒立摆的串级控制要补两个公式外的细节

`cascade_cartpole()` 里有两处不属于 PID 公式的工程处理，正文第 21 节单独讲了：

- **内环输出取负号**：杆子往右倒，车要往右推。
- **外环输出限幅 ±0.15 rad**：不让位置环为了追位置而把杆子甩倒。

这两个细节是搜索参数时反复发散之后才定下来的，不是一开始就写对的。
