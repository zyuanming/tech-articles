# 运行递归下降小实验

这是本篇原创 Python 教学解析器 v1，只支持 ASCII 十进制整数、加减乘和括号，不是 Oberon-0 编译器。代码、HTML与重算JSON采用 CC0 1.0；正文PNG采用CC BY 4.0。原书代码没有复制到本目录。

在本目录中，Python 3.12 可直接运行解析与实验，无需第三方库：

```sh
python parser.py '12-3*2-1'
python experiment.py
```

前一命令输出tokens、节点、实际调用事件及求值结果5；后一命令重写同目录 `results.json`。实验对9,331个长度至多5的短字符串穷举，与独立运算符栈识别器比较；另检查括号、错误位置和长度限制。

节点编号是 `nodes` 数组索引。运算节点的 `left`、`right` 是孩子编号，不是操作数的数值。`values` 在成功解析并确认EOF之后计算；构建事件不提前求值。HTTP接口仅把成功结果中的 `value` 与 `values` 元素转换为十进制字符串，以免浏览器JSON解析丢失大整数精度；节点编号仍是整数。`parser.py` 命令行输出与 `results.json` 保持Python整数，不受展示协议转换影响。事件中的 `index` 是事件发生时的token游标，`consume`事件记录之后才移动。

启动实际教学页：

```sh
python server.py
```

浏览器访问本机 `http://127.0.0.1:8825/`，输入表达式并点击“解析并求值”。服务只绑定本机回环地址。输入上限256字符、单个整数上限9位、括号上限32层；HTTP请求体超过4096字节拒绝。页面会显示HTTP、网络或JSON错误，修正输入或恢复服务后可重试。结束时在启动终端按 Ctrl+C。此服务器仅供本地教学，不是生产部署方案。

三层核心解析过程在 `parser.py`。`experiment.py` 独立计算FIRST/FOLLOW/SELECT集合，并运行主动限定四层的左递归错误探针；它不会尝试让Python栈真正溢出。固定的输入、测试字符集与长度都写在源码和JSON中，无随机性。

如需重绘机制图，需 Pillow、fontTools 及 Noto Sans CJK 字体。字体缺失时会报错，不退回不能显示中文的默认字体。

```sh
python build_figures.py
```

默认重绘 `assets/00` 至 `assets/12`，同时更新本目录的图像元数据。实际图13、14为浏览器截图，绘图脚本不生成或改写其像素。

要比较重绘字节，可以输出到文章目录以外的相对路径，按实际工作目录调整：

```sh
python build_figures.py \
  --out ../../../../wirth-check
```

此命令仍会重写本目录元数据；复验冻结稿时，请先复制整个文章到独立工作副本再运行。不要把临时审计文件放入公开文章目录。

原书与原图的核读限制、逐图作用和完整权利范围见[来源清单](../sources.md)。
