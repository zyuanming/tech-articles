# 无穷与对角线：可复算材料

正文：[read.md](read.md)。来源与许可：[sources.md](sources.md)。

这一篇的论证**一支笔一张纸就能走完**。代码在这里做三件事：把配对检查一遍、把对角线构造真的跑出来并逐行核对、把幂集的数字列出来。

## 运行

环境记录见 [run-environment.json](examples/run-environment.json)。**全部代码只用 Python 标准库**（绘图另需 Pillow 与一款中文字体）。

```sh
python examples/run_model.py        # 全部实验，写 results.json
python examples/build_figures.py    # 重绘全部正文图与封面
```

## 四组实验

### 1. 配对校验

对每个声称的配对，检查前 1000 个（有理数那组是 1600 个）取值：

- 有没有重复（单射）；
- 有逆映射的，往返是否回到原处。

全部通过。**注意这只是有限范围的检查**，见下面的限制。

### 2. 对角线构造

三轮。每一轮都对表里**每一个**数逐行核对"新数确实与它不同"，并报告第一个不同的位置。加进去再构造一次，仍然逃出。

### 3. 幂集

n = 0 到 10 的 2ⁿ 与 n 的比较，以及 n = 0 到 7 时"二进制串个数"与"子集个数"的逐个核对。

### 4. 希尔伯特旅馆

只模拟前若干间房，用来说明移位规则，并检查移位后没有两个人拿到同一个房号。

## 一个必须处理的细节：为什么避开 0 和 9

`0.4999…` 与 `0.5000…` 是**同一个数**的两种写法。

如果构造出的新数尾巴上全是 9（或全是 0），它就可能和表里某个数"**写法不同而数值相同**"——那样它其实还在表里，整个论证就垮了。

所以 `diagonal_number()` 的 `safe_digits='12345678'` 让新数的每一位只从 1 到 8 里取，这样它永远不会有 9 或 0 的尾巴，写法唯一。

**代码里的注释写明了这一点。** 一个证明里最脆弱的地方，往往就是这种"看起来显然"的细节。

## 文件

- [infinity.py](examples/infinity.py)：配对函数、对角线构造、幂集、二进制串。
- [run_model.py](examples/run_model.py)：全部实验，输出 `results.json`。
- [figkit.py](examples/figkit.py)：绘图工具。保存前检查文字是否出画布、是否越出所声明的框、是否互相重叠、字号下限、对比度。
- [build_figures.py](examples/build_figures.py)：全部正文图与封面。

## 限制

- **所有配对校验都在有限范围上做**（前 1000 或 1600 项）。有限范围的检查**不能证明无穷情形**，它只能排除明显的重复与遗漏。数学上的证明在正文里，代码只是把前几步实际跑出来给读者看。
- 没有核对希尔伯特旅馆这个例子的原始出处。
- 没有核对希尔伯特那句话的德语原文，引用的是英译。
- 没有复现图灵 1936 年论文原文。
- 没有讨论选择公理、连续统假设或基数算术。
- 正文最后一个问题（0 到 1 之间的分数与小数哪个多）**没有给出答案**。
