# MapReduce十二词示例：附属材料

本目录配套《把词频统计分给一百台机器，最难的是哪一步？》。直接阅读read.md即可理解主线；运行代码是可选补充。

## 数值复现

要求：Python 3.9或更高版本，只有标准库；无需网络、Hadoop、服务器账户或真实集群。原始校验环境和绘图依赖版本见下方记录。

在examples目录执行：

```sh
python3 wordcount.py
```

程序读取corpus.json，重写results.json与output.txt。原始语料只包含cat、dog、bird、fish，使用显式ROUTE表，目的在于让分区去向可手查；它不是通用分词器或通用分布式实现。

应得到：bird=2、cat=5、dog=3、fish=2；输入12词；不合并时12对、每个map本地合并一次后9对；原分区5/3/4；在A末尾新增100个cat后105/3/4；先合并再发送变3/2/4；415个测试情景通过。固定随机种子20261013。重跑结果JSON和输出文本应逐字节相同。

wordcount.py中的accept_first_complete只展示“一个任务只采用一份完整尝试结果”的选择规则，没有网络、崩溃恢复、实际临时文件提交或并发一致性。原论文的原子提交与失败恢复由正文单独说明，不能用本程序的通过结果声称验证了生产框架。

## 图片复现

数值文件生成后，再执行：

```sh
python3 build_figures.py
```

这一步需要Pillow及Noto Sans CJK字体。脚本默认使用Linux下的字体路径/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc与NotoSansCJK-Bold.ttc。其他环境需要修改这两条字体路径；字体不同可能导致图片字节不同，但不应改变数值结果。字体索引2对应本次所用字库的简体中文样式。

脚本生成20张正文原创图（含实际数值结果卡）和一张独立封面，保留第三方原照片不作修改。figure-metadata.json列出图像职责和字号参考。正文21幅配图中另1幅是机架实拍，来自sources.md记录的独立许可。

## 范围

- 没有真实网络传输，也没有集群性能测量。
- 慢任务图的0/3/5/8秒是教学设定。
- 热点柱图单位是键值对条数，不是秒数或字节数。
- 12→9表示记录条数，不能据此推断总网络字节数减少25%。真实记录有编码、键长、文件和协议开销。
- 整数计数在Python中采用任意精度整数；没有验证具体产品的定长整数溢出行为。
- 所有输入为人工构造，无私人文档和用户数据。
