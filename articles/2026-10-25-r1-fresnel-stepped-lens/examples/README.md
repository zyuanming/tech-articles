# 复算本文的薄元件光线模型

从本目录运行：

```sh
PYTHONDONTWRITEBYTECODE=1 \
  python trace.py
PYTHONDONTWRITEBYTECODE=1 \
  python build_figures.py
```

第一条命令仅需 Python 标准库，重建 `results.json`。第二条使用 Pillow、fontTools 与 Noto Sans CJK 字体，重建正文 PNG 和 `figure-metadata.json`。本次使用 Python 3.12.14；生成器在缺少中文字体时直接报错，不静默替换字体。没有随机输入。

## 输入和模型

`trace.py` 顶部的 N、F、R 分别是设计折射率、目标焦距和孔径半径；长度单位 mm，Python 三角函数使用弧度，JSON 角度读数换成度。默认 n = 1.49、f = 200、R = 50。空气折射率为 1，入射光沿 +z，先正入射到平面，然后从斜面进入空气；所有出射交点放在 z = 0。

`slope(r)` 从目标偏转角 `atan(r/F)` 反求法线角；`bend(alpha,n)` 用 Snell 定律回算实际偏转。`None` 表示材料到空气方向没有透射解。这是一项薄参考面模型，不生成加工曲面，不处理基底厚度、真实槽壁与射线相交，也不计算衍射。

反求公式限定在当前 n > 1、平面入射且斜面出射的模型，并要求正向透射分支：α + θ ≤ 90°，等价地 θ ≤ acos(1/n)。等号是沿出射界面传播的掠射极限；模型量 `max_exit_deflection_deg` 记录这个最大偏转角，即 90° − asin(1/n)，以度为单位。默认 n = 1.49、f = 200 mm、r ≤ 50 mm 满足条件。修改 N、F 或 R 后必须重新核对该分支，不能只凭反求公式返回了一个角度就认定光线能按目标方向透射；本程序不是通用光学求解器。

槽距输入分别为 10、5、1 mm；每一圈按中点求一条固定斜率，再在该圈取 11 条径向光线。统计量是固定焦面上的最大绝对径向残差，不是像质分辨率。中心端点按一条径向的极限处理，不能据此推断真实产品的中央曲面。

其他对照均另行声明：固定 r = 40 mm 斜面、把 n 改为 1.48/1.50；固定每槽径向坏区宽 0.05 mm；局部球面方向的母球半径为 `(n−1)f`；有限物距例子改用薄透镜近轴公式，u = 1000 mm、物宽 2 mm。它们都不是实机测量。

## 反射计算怎样读

`reflect(i,n1,n2)` 先算透射角 t，再计算 s 与 p 两个偏振的振幅反射系数；把各自平方后等权平均，得到非偏振光功率反射率。默认只用于实数、无吸收、可透射的界面。

令 A = n1 cos i，B = n2 cos t，则 s 分量的振幅反射系数为 `(A−B)/(A+B)`。p 分量对应把分子、分母中的两个折射率交换：先令 C = n2 cos i，E = n1 cos t，再算 `(C−E)/(C+E)`。两分量取平方后平均。符号约定不影响这里的功率平方。

第一面固定正入射，第二面入射角是工作面法线角。两面首程直透比例为各自 `(1−R)` 的乘积。这里不加回内部多次反射，不计算干涉、镀膜、吸收、槽缘或目标接收孔径。
