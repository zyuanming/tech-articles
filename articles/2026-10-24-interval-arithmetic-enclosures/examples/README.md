# 运行与范围

Python 3 + Pillow + fontTools + Noto Sans CJK。运行 `python lab.py`。

核心区间操作add/sub/mul/sq/div使用有理数端点；除法输入若含零就抛异常。不实现空区间、无穷端点、超越函数、IEEE 1788装饰区间或生产级接口。Fraction输入用整数或字符串构造；先把测量变成float再转Fraction不会恢复丢失的原始信息。

程序以6300项有限网格断言核验加减乘包含性，并计算x(1−x)在1/2/4/8/16段下的包围。普遍包含性由正文代数推导，不是抽样证明。显示坐标转换为float仅影响绘图，不影响保存前的有理数区间计算。代码、数据和图片CC BY 4.0。
