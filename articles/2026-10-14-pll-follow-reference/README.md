# PLL教学模型：可选复现

正文：[read.md](read.md)。这是原创离散相位反馈模型，不是实物电路仿真，也不是复刻文中照片设备。

## 环境

本次运行使用Python 3.12.14、NumPy 2.3.5。制图另使用Pillow 12.3.0与Noto Sans CJK Regular/Bold；脚本开头的字体路径可按本机字体位置修改。没有自动下载、安装或网络访问。

在本文目录执行，输出目录必须为空或不存在：

```sh
python3 examples/simulate.py --out ./my-results
```

结果包括results.json、comparisons.npz和hashes.json。results保存主运行、P-only、除4、采样混叠实验的所有状态及检查结果；npz保存快慢跟踪与两类扰动对比的完整数组；hashes记录输出文件SHA-256。固定的本次[expected-results.json](examples/expected-results.json)供对照。浮点末位不保证跨版本逐字节相同。

## 主运行规则

相位单位为圈，频率为Hz即圈/秒，时间为秒。这里有意放慢节拍，便于看图，并不代表现代芯片使用1 Hz工作时钟。

- 参考1 Hz，初始参考相位0.25圈。
- 本地初始累计相位0，未控制的自由频率0.8 Hz。
- 每0.1秒检查一次，共显示0至30秒的301次检查。
- Kp=1 Hz/圈，Ki=0.5 Hz/(圈·秒)，初始累计频率修正z=0。
- 每次先读取当前相位，将差包裹到[-0.5,0.5)，再更新z，再决定下一段频率，最后推进相位。

具体顺序：

```text
feedback_phase = output_phase / N
error = wrap(reference_phase - feedback_phase)
z = z + Ki * dt * error
frequency = free_frequency + Kp * error + z
output_phase = output_phase + dt * frequency
```

N=1是主例。参考也随相同的dt前进；它不会随着本地误差改变。输出完整相位允许超过1圈，只有比较差值时做wrap，不能每步把累计输出圈数丢掉。

程序采用理想、直接可设的频率执行器。没有调谐上下限、电荷泵、相位频率检测电路、固定点量化、传播延迟或电压到频率非线性。大频差下wrap观测可能混叠；最后的11 Hz反例正是展示这个限制，不给它补一个未经说明的真实PFD。

## 可核对结果

- 第0次：e=0.25圈，z=0.0125 Hz，输出1.0625 Hz。
- 第1次：e=0.24375圈，z=0.0246875 Hz，输出1.0684375 Hz。
- 主运行末端：e约−1.2531e−8圈，输出约1.0000000112 Hz，z约0.2000000237 Hz。
- P-only只令Ki=0，其余不变：最终e约0.2圈，频率约1 Hz。
- 除4：N=4，自由频率3.2 Hz，Kp=4、Ki=2，其余时刻/初值按代码；最终输出约4.0000000448 Hz。系数与自由频率按输出尺度乘4，不宣称只插一个除法以后瞬态原样不变。
- 错认反例：参考1 Hz、本地自由频率11 Hz、两路初相0，每0.1秒比较；两路一圈内读数一致，误差仅有浮点舍入量级，本地没有实际同频。

无wrap折返、固定参考频率下，主例误差e和累计修正z的小信号更新矩阵为：

```text
[1-Kp*dt-Ki*dt^2,  -dt]
[       Ki*dt,        1]
```

两个特征值模均约0.9486833，小于1。这是确切离散更新顺序的局部线性稳定检查，不保证任意初态全局捕获。脚本保留最终收敛与量纲对应的断言。

## 快慢与扰动对比

这些是独立实验，时间步改为0.02秒：

- 快：Kp=2、Ki=1。
- 慢：Kp=0.4、Ki=0.04。
- 跟踪实验：第30秒参考频率1→1.2 Hz，相位保持连续，总时长80秒。进入并在该次剩余观察区间保持1.2±0.01 Hz，分别约需4.12秒、20.72秒。这里0.01 Hz是绝对误差带，并非目标1.2 Hz的1%。
- 参考扰动：参考相位加0.03×sin(2π×0.8×t)圈，总时长140秒。
- 本振扰动：本地自由频率加0.04×sin(2π×0.08×t) Hz，参考不加扰动，总时长140秒。
- 两种扰动实验都在100≤t<125秒计算输出相位相对干净参考的偏离，去均值后取总体均方根，即NumPy的std默认ddof=0。

输出相位波动RMS：

- 参考扰动：快0.0083524949圈，慢0.0016949124圈。
- 本振频率扰动：快0.0113223662圈，慢0.0487015229圈。

这些确定性的正弦探测信号不是测得的随机相位噪声谱，也没有遍历所有调制频率。只比较同一个输入源下两组环路；不能用两行数字给不同实际噪声来源排序。程序不使用随机输入。
